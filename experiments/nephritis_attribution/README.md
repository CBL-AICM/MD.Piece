# 腎炎機轉歸因模型（nephritis_attribution）

**做什麼**：從已經存在的常規檢驗資料，判斷一位腎炎病人的**病因機轉**（免疫沉積／壞死內皮／足細胞屏障），
輸出以二元 rule-out 為主、三驅動排序與混合旗標為輔。零新增檢驗。

**不做什麼**：不預測預後、不預測腎功能下降、不取代腎切片、不宣稱診斷。

---

## 1. 命題

> 腎炎的臨床困難不在「有沒有腎炎」，而在「是哪一種機轉的腎炎」——
> 因為治療完全不同（免疫抑制 vs 停藥 vs 血漿置換 vs 支持性治療），
> 而分辨機轉目前依賴血清學套組與腎切片，兩者都慢、貴、且不是每家醫院都做得到。

所以主要標籤是**組織型態**（腎切片型態學）而不是臨床診斷名。
臨床診斷名是用血清學下的，再拿血清學相關特徵去預測它就是循環論證。

八種組織型態：`IC_PROLIF`（免疫複合體增生）、`MEMBRANOUS`（膜性）、`PAUCI_CRESCENTIC`（寡免疫新月體）、
`ANTI_GBM`、`TMA`、`PODOCYTOPATHY`（足細胞病）、`TIN`（間質性）、`SCLEROTIC_NONINFLAM`（硬化／非發炎）。

---

## 2. 兩層架構

```
決定性標記（已在病歷裡）  ──有──▶  L2 硬分流：純 if-else，直接定案，不進模型
                          │
                          └──沒有／還沒回──▶  L3-L5：常規資料模型
```

關鍵是**「標記還沒回來」與「標記陰性」是兩個不同狀態**，程式裡分成兩個欄位。
把未回覆當陰性，是這類系統最典型的靜默錯誤。

模型從不「加驗」任何檢驗——它處理的正是決定性標記缺席時的那段空窗。

---

## 3. 五層管線

| 層 | 做什麼 | 用什麼決定 | 檔案 |
|---|---|---|---|
| **L1** 資料品質 | 缺值、單位錯置、不可能值、時間窗過期 → 棄權 | 純門檻 | `src/pipeline.py:l1_quality` |
| **L2** 決定性標記 | 抗 GBM／ANCA+RPGN／TMA 三聯／抗 PLA2R+腎病症候群 → 硬分流 | 純 if-else | `src/deterministic.py` |
| **L3** 二元免疫判定 | 「免疫介導腎絲球腎炎」是／否，操作點壓在 NPV 端 | 邏輯迴歸 + 安全約束門檻 | `src/pipeline.py:fit_l3` |
| **L4** 三驅動歸因排序 | 固定 Λ 的 NNLS，輸出三驅動占比與各自的貢獻指標 | 非負最小平方 | `src/attribution.py` |
| **L5** 混合旗標 | 混合驅動、間質疑似、血管炎優先、血清學未回 | 純門檻 | `src/pipeline.py:l5_flags` |

L3 之後還有一道**單向的決定性否決**（`deterministic.safety_override`）：
肌酸酐每週爬 ≥0.15 mg/dL 或已升血管炎旗標者，一律不得被 rule out。
只能取消 rule-out、不能製造 rule-out——讓確定性規則推翻機率是安全的，反過來不是。

## 4. 六項設計裁決

### 4.1 負載矩陣文獻固定 ＋ NNLS，不自由估計

自由估計（EFA／PCA）的解只在旋轉意義下唯一：對任一可逆 `R`，`(ΛR, R⁻¹a)` 與 `(Λ, a)`
產生**完全相同**的模型隱含共變。所以「哪個因子叫免疫沉積」在資料裡沒有答案，命名是分析者
事後看載荷猜的。歸因偏偏是要對被命名的機轉下結論——旋轉不確定性因此不是精度問題，是識別問題。

**已跑出數字**（閘門 G3）：24 個隨機正交旋轉下，非對角擬合最大偏差 `5e-16`（＝完全相同），
但同一位病人的主導驅動在旋轉間的一致率只有 **0.227**，平均會被指派到 **2.92 個不同的驅動**（共 3 個）。
固定 Λ 的 NNLS 準確率 0.814。

### 4.2 只用非對角

模型隱含共變 `Σ = ΛΨΛᵀ + Θ`，`Θ` 是對角（各指標的獨特變異與量測誤差）。只擬合 `i≠j` 時 `Θ` 整個消掉：

1. 少估 20 個獨特變異參數，自由度全給 `Ψ` 的 6 個；
2. 沒有任何指標能「自己解釋自己」；
3. 擬合優度變成真正的證偽測試。

**已驗證**（`tests/test_core.py`）：對 X 灌入純獨立雜訊（只膨脹對角），`Ψ` 估計與非對角 RMSE 幾乎不動。

**已跑出數字**：Λ 結構誤設 10% 時，非對角 RMSE 立刻從 0.356 跳到 0.530；
而幅度誤設 50% 只讓 RMSE 到 0.582、top-1 準確率幾乎不掉（0.829→0.826）。
→ 非對角統計量對「指標歸錯驅動」敏感，對「權重估錯大小」不敏感——這正是我們要它偵測的那種錯。

### 4.3 禁逐人標準化

逐人標準化＝把每個病人的檢驗值對他自己的分布正規化。問題不只是準確率，是**洩漏**：
回溯研究算那個分布時手上有整段病程（含當次），上線後只能用過去的資料算。

**已跑出數字**（閘門 G4，殘餘子集）：

| 做法 | AUROC |
|---|---|
| A 絕對刻度（本模型採用） | **0.902** |
| B 逐人標準化・含當次（論文通常報的數字） | 0.719 |
| C 逐人標準化・只用過去（上線後唯一拿得到的） | 0.563 |

洩漏膨脹 B−C = **+0.156**；相對絕對刻度的代價 C−A = **−0.339**。

誠實補充：較弱的橫斷面變體（逐人跨指標 z）只讓 AUROC 掉到 0.894。
**不是所有形式的逐人縮放都一樣糟**，混為一談會失去說服力。

### 4.4 M0 洩漏基準先建

M0 故意作弊：可看切片免疫螢光強度、新月體比例、事後有沒有開免疫抑制劑、編碼診斷、追蹤 eGFR。
它有三個用途——天花板、絆線、以及「哪些欄位一旦混進特徵集就會毀掉研究」的清單。

**已跑出數字**：M0 免疫二元 AUROC **0.999**、組織型態 macro AUROC 0.990（準確率 0.925）。
訊號主要來自 `icd_group`(0.35)、`if_deposit_intensity`(0.34)、`immunosuppressant_started`(0.16)。
誠實模型 M1 是 0.900，差距 0.099（閘門 G5 要求 ≥0.02）。

第一版跑出來時 M1 是 0.981、只差 0.019 → **G5 直接擋下**，逼出「合成世代過於好分」的問題。
絆線有作用，這就是它先建的價值。

### 4.5 二元輸出為主

不做八分類 softmax。理由：混合病理（狼瘡＋抗磷脂 TMA、膜性＋足細胞）在真實世界常見，
softmax 的互斥假設會把重疊病理壓成一個錯的單一答案。
每個機轉各自是一個二元頭，並且允許同時有多個旗標。

### 4.6 組織型態標籤為主

見第 1 節。次要標籤（臨床診斷名、治療反應）一律列入 M0 的洩漏特徵清單。

## 6. 目前結果（合成世代，n=6000，seed 20260827）

| | 轉介族群 referral | 基層／一般腎臟科 primary |
|---|---|---|
| 免疫性 GN 盛行率（殘餘子集） | 0.509 | 0.159 |
| L1 棄權率 | 8.9% | 8.9% |
| L2 硬分流覆蓋 / 正確率 | 8.8% / **87.3%** | 2.8% / **65.9%** |
| L3 AUROC | 0.900 | 0.929 |
| rule-out 覆蓋（只看 NPV≥0.95） | 14.4% | **82.7%** |
| rule-out 覆蓋（加安全上限） | 9.2% | 5.2% |
| 免疫＋時效性漏判 | 2/507 = 0.39% | 0/63 = 0% |
| 三驅動 top-1 準確率 | 0.814 | — |

三個必須講清楚的發現：

1. **NPV 端能不能落地，決定於部署在漏斗的哪一段。** 同一個模型，在盛行率 51% 的轉介族群只能安全排除 14%，
   在盛行率 16% 的基層族群可以排除 83%。KidneyIntelX 的低風險層能覆蓋約一半病人，很大一部分是低盛行率的紅利，
   不是模型比較強。照抄它的數字而不對齊盛行率，會得到錯誤的商業推論。

2. **決定性層不是盛行率免疫的。** L2 正確率在轉介族群 87.3%，在基層族群掉到 65.9%——
   標記的偽陽性率沒變，但盛行率降了，PPV 就跟著掉。「決定性」指的是「不用模型、不算機率」，
   不是「不會錯」。硬分流只在富集族群裡安全，用在基層需要補一道確認步驟。

3. **樣本量由安全終點決定，不是由 AUROC 決定。** 要用三法則證明時效性型態漏判率 ≤0.5%，
   需要 ≥600 位抗 GBM／寡免疫新月體個案。本世代 referral 只有 507、primary 只有 63，
   **兩者都不足以支持安全宣稱**（`safety_endpoint_powered: false`）。
   在小的時效性子群上，0.5% 的上限實際等於「一個都不能漏」，操作點會被單一個案的位置決定，不穩定。

## 7. 介面（`ui/`）

```bash
cd experiments/nephritis_attribution && python ui/export_ui_pack.py
```

產出單一檔 `ui/index.html`（可雙擊開啟、離線、零外部連線）。四個分頁：

| 分頁 | 內容 |
|---|---|
| **試算** | 22 個常規檢驗欄位＋4 個決定性標記（未回覆／陰性／陽性三態），跑完 L1→L5 給出即時判定。可「載入範例病人」或「填入參考點」自動帶入 |
| **完整報告** | 八節結構化報告：結論／產生方式／輸入摘要／五層逐層說明／數據視覺化／相容型態鑑別順序／建議下一步／**這份報告不能告訴你什麼**。附列印樣式，可直接存成 PDF |
| **批次計算** | 貼上 TSV／CSV 一次跑多例，輸出結果表與摘要，可下載 CSV |
| **模型內部** | 五層漏斗、負載矩陣 Λ 熱圖、旋轉不確定性演示（4 個擬合相同但歸因不同的解）、NPV／覆蓋率權衡曲線、Λ 誤設退化曲線、六道閘門 |

報告裡的數據視覺化有三張：三驅動組成長條、**各指標偏離圖**（本例 vs 世代中位數與第 90 百分位，超標者標紅）、
**世代位置圖**（本例的機率落在殘餘子集分布的哪個百分位，與門檻的相對位置）。
一個機率值單獨看沒有意義，要有同類病人的分布當參照。

四條設計約束：

1. **前端不得實作模型。** L3 的標準化統計與迴歸係數、L1/L2/L5 的門檻、世代分布參照，全部由
   `ui/export_ui_pack.py` 從模型端匯出；前端只做 `(x−mean)/scale`、內積、sigmoid 與 3 變數 NNLS（列舉 8 個支撐集的精確解）。
2. **前端每次載入自我校驗。** 資料包內含 12 個模型端算好的黃金案例，開啟時重算比對，
   一致顯示「✓ 與模型端一致 12/12（最大偏差 7.5e-6）」，不一致就把偏差印在畫面上。
3. **所有文案放參數檔。** 建議（`actions`）與報告的逐層敘述模板（`narrative`）都在
   `params/deterministic.json`，不寫在 JS —— 文案與模型分家會讓兩者各自漂移，而漂移的是給人看的那一半。
4. **報告與試算同一次計算產生**，不各算一次。兩邊各算遲早會給出不同答案。

相容型態候選是**呈現用**的（把三驅動占比比對各型態的驅動輪廓），沒有以組織型態訓練或校準過；
畫面與報告上一律附實測 top-1 **48.3%** / top-3 **81.2%**（n=4940）。

**上正式站**（預設不會發生，必須明確指定）：

```bash
cd experiments/nephritis_attribution && python ui/export_ui_pack.py --publish
```

寫入 `frontend/nephritis-model.html`，走 `vercel.json` 既有的 `frontend/**` 靜態規則，
合併 main 後路徑為 `https://www.mdpiece.life/nephritis-model.html`。
預設不寫是刻意的：這頁一旦躺在 `frontend/`，任何一次為了別的理由合併 main 都會把它推上公開醫療網域。
頁面本體帶有研究用途聲明橫幅與 `noindex,nofollow`。

## 8. 已知限制

- 合成資料**不能**驗證文獻 Λ 是否正確、真實盛行率、真實 NPV。詳見 [results/assumptions.md](results/assumptions.md)。
- 本版不涵蓋：單株免疫球蛋白相關腎病、類澱粉沉積、遺傳性腎絲球病、移植排斥。
- `TIN`／`TMA` 不在 L3 二元的陽性集合裡，改由 L5 旗標處理；TMA 完全無旗標離開系統的比率為 2.1%（referral）／7.1%（primary），
  這是目前最弱的一環。
- L3 用邏輯迴歸而非梯度提升，是刻意的：在 20 個方向化指標上，可解釋性與校準比 1-2 點 AUROC 值錢。
- **適用範圍**：轉介世代裡不存在「所有常規指標皆正常」的人，模型對這種輸入只能外推。
  介面因此加了適用範圍閘（全零向量直接不給機率）與外推警示（指標超出訓練 1–99 百分位時明示）。
  這是做出試算器才發現的問題 —— 見 [results/assumptions.md](results/assumptions.md) C.5。

## 9. 與 KidneyIntelX 路線的關係

見 [docs/商業化前例_KidneyIntelX對照.md](docs/商業化前例_KidneyIntelX對照.md)：
「常規資料＋機器學習、靠 NPV 端落地」已經走通監管與給付，
差異在**它做預後、我們做病因歸因**，以及**它加驗三項血漿標記、我們零新增**。
