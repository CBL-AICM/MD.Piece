# 六條公式的可用性評估

評估方式：在既有合成世代上實測，不做主觀判斷。所有比較在**同一個殘餘子集、同一組安全否決、
同一個門檻規則**下進行，只換 L3 的特徵集，否則差異可能來自別的地方。

重現：`python run_formulas.py --casemix referral|primary --n 6000`
原始輸出：`results/formula_eval_referral.json`、`results/formula_eval_primary.json`

## 逐條

### 公式 1–2：變化量與變化率 —— 可用，但價值高度依賴族群

| 特徵集 | 轉介族群 AUROC / 可排除 | 基層族群 AUROC / 可排除 |
|---|---|---|
| 只用當次（現行） | 0.8987 / 6.4% | 0.9336 / 9.2% |
| ＋ΔX | 0.9034 / 5.5% | 0.9417 / **23.6%** |
| ＋Slope | 0.9020 / **9.0%** | 0.9396 / 8.2% |
| ＋兩者 | **0.9056** / 8.6% | **0.9434** / 20.7% |

AUROC 的增益很小（+0.007～+0.010），但**可安全排除的比例在基層族群提高 2.5 倍**。
這與先前的盛行率結論一致：AUROC 是全域指標，NPV 端的操作點只看機率分布最低的那一段，
縱向特徵剛好在那一段幫得上忙。**只看 AUROC 會低估這兩條公式的價值。**

⚠️ 這個結論一度是假的。第一次跑的時候增益幾乎是零，原因在生成器：既往面板是用
`A × 固定衰減 × Λ` 造的，軌跡不帶任何新資訊，Δ 與 Slope 只是當次值的雜訊縮放版。
改成**型態專屬的病程速率**（新月體型與抗 GBM 陡升 0.75–0.85、膜性緩慢 0.12、硬化型近乎持平 0.05）
之後才問得出真問題。原本的生成器是為 G4 洩漏測試寫的，不是為了承載軌跡訊號。

**已整合**：介面的試算分頁多了「既往檢驗（可選）」區塊。只要一次既往抽血＋距今週數就會
自動改用縱向模型，並在結果上標明用了哪個模型。刻意用「使用者拿得出來的形式」（一個既往面板）
訓練部署版本，而不是評估時的三面板理想形式 —— 否則上線後餵進去的東西與訓練時不同。

### 公式 3：線性混合模型 —— 三個時間點不夠，問題出在跨度不是點數

隨機斜率的 BLUP 收縮係數（1 = 完全採用個人斜率，0 = 全部收縮到族群平均）：

| 族群 | 平均收縮係數 | BLUP 與簡單斜率相關 | AUROC 相對簡單斜率 |
|---|---|---|---|
| 轉介 | 0.060 | r = 0.549 | **−0.0007** |
| 基層 | 0.012 | r = 0.228 | **−0.0027** |

收縮係數 τ²/(τ²+σ²/S_tt) 幾乎為 0，代表**三點估出來的個人斜率基本上是雜訊**，
混合模型正確地把它幾乎全部收掉。收掉之後就沒有資訊了，所以 AUROC 不升反降。

反推追蹤設計需求（目前是 3 點、跨度 12 週）：

| 目標收縮係數 | 轉介族群 | 基層族群 |
|---|---|---|
| 0.5 | 3 點 / 跨度 **48 週** | 3 點 / 跨度 **114 週** |
| 0.8 | 3 點 / 跨度 **96 週** | 3 點 / 跨度 **228 週** |

**綁死的是跨度，不是點數**：S_tt 隨跨度平方成長、隨點數線性成長，所以「多回診幾次」的效益
遠不如「拉長觀察窗」。這對研究設計是可執行的結論。

另有兩點要記著：族群層的 β₁ 在這個世代裡沒有意義（同時混著惡化中的血管炎與穩定的硬化型，
平均起來不代表任何人）；以及方向化指標有地板效應（`max(0,·)`），LMM 的常態假設在低值區被破壞。

環境沒有 `statsmodels`，實作用平衡設計下的封閉解 BLUP —— 那不是近似，是同一個估計量。
若日後改成不平衡設計（每人回診時間不同），封閉解不成立，必須換真正的 LMM 求解器。

### 公式 4–5：多類別 softmax —— 最大的一筆改善，而且推翻了我先前的判斷

| 方法 | 轉介 top-1 / top-3 | 基層 top-1 / top-3 | 校準誤差 |
|---|---|---|---|
| 現行餘弦候選清單 | 0.477 / 0.811 | 0.426 / 0.756 | 未校準 |
| softmax（常規） | 0.732 / 0.941 | 0.831 / 0.973 | 0.010–0.014 |
| softmax（＋縱向） | **0.760 / 0.954** | **0.853 / 0.979** | 0.016–0.017 |

我先前把「二元輸出為主」的理由寫成「softmax 的互斥假設會把重疊病理壓成一個錯的答案」，
並據此用驅動輪廓的餘弦相似度湊了一份候選清單。**在這份資料上那個判斷是錯的**：
餘弦清單 top-1 只有 0.43–0.48，softmax 到 0.76–0.85，而且校準良好（ECE ≈ 0.01–0.02）。

原論證仍然有效的部分：softmax 確實無法表達重疊病理。但**本世代每人只有一個組織型態標籤，
根本測不出這個代價** —— 也就是說，資料的結構本身就偏袒 softmax。兩件事都要講。

**已整合**：餘弦候選清單已移除（它是個 hack，而且嚴格較差），改用以組織型態訓練的多類別頭，
介面與報告顯示完整的 P(Y=k) 分布而非單一答案，並附上互斥假設的警語。

**未整合，留給你決定**：把二元 rule-out 改成由 softmax 加總（Σ_{k∈免疫} P(Y=k)）。
兩個族群給出**相反**的答案：

| | 直接訓練二元 | 由 softmax 加總 |
|---|---|---|
| 轉介 | 0.9056 / 覆蓋 8.6% | **0.9348 / 覆蓋 13.6%** |
| 基層 | **0.9434 / 覆蓋 20.7%** | 0.9464 / 覆蓋 10.9% |

方向不一致，而且二元頭是**安全關鍵**的輸出。只憑合成證據換掉它不合適，列為待裁決事項。

### 公式 6：需要先定義 Y，否則是循環的

把「病理特徵」（免疫螢光沉積強度、新月體比例）依公式 6 逐字放進預測變項：

| | 轉介 top-1 / macroAUC | 基層 top-1 / macroAUC |
|---|---|---|
| 只用常規 | 0.760 / 0.955 | 0.853 / 0.948 |
| ＋病理特徵 | 0.859 / 0.981 | 0.896 / 0.981 |
| 增益 | **+0.099** | **+0.043** |

這與本專案 M0 洩漏基準量到的是同一件事（M0 把切片所見放進特徵，組織型態 macroAUC 0.99、
免疫二元 AUROC 0.9996）。**若 Y 是組織型態，公式 6 這樣寫就是循環的** —— 分數會很漂亮，
但那是答案在特徵裡。

若 Y 指的是**病因亞型**（狼瘡／IgA／ANCA 相關／感染後…）而病理特徵是組織型態，
則不循環 —— 那是臨床上本來的推理方向（型態 → 病因）。**這兩者必須先講清楚是哪一個。**
目前本模型的 Y 是組織型態，所以公式 6 不能照抄。

另外，公式 6 其實就是公式 5：把 X_ij 換成具名的變項群之後，Score 與 η 是同一個東西，
softmax 之後就是公式 4。這不是挑語病 —— 把同一個模型寫成三條，容易讓人以為驗證了三次。

### 附帶：自體抗體組合要不要進模型

公式 6 列了「自體抗體組合」。實測把 anti-GBM／ANCA／anti-PLA2R／MAHA 三聯放進 L3 特徵：

| 族群 | 留在 L2 硬分流 | 放進模型當特徵 | 增益 |
|---|---|---|---|
| 轉介 | 0.9056 | 0.9180 | +0.0124 |
| 基層 | 0.9434 | 0.9504 | +0.0070 |

**建議維持現狀（留在 L2）**：換到 +0.007～+0.012 的 AUROC，代價是「零新增檢驗」不再成立，
而那是與 KidneyIntelX 路線唯一的結構性差異，也是成本結構的全部優勢來源。這個交換不划算。

## 一個測不出來的東西，必須誠實講

公式 1–2 的 `t₂ − t₁` 沒有規定 t₂ 落在決策點的哪一側。回溯資料庫裡「上一次」與「下一次」
抽血長得一樣近，SQL 的不等號寫反就會把決策後的資料抓進來。我做了洩漏演示，結果是
**測不出膨脹**（−0.0015／+0.0024）。

原因是生成器的「未來面板」是當前狀態的確定性外推加雜訊，不帶新資訊。真實世界的未來面板
會反映**治療反應**，而治療反應與標籤強相關（免疫抑制對免疫性腎炎有效）—— 洩漏正是在那裡發生。
本生成器沒有治療。

所以這條的證據不是來自這個 null 結果，而是來自 M0：M0 的洩漏特徵集裡就含
`immunosuppressant_started` 與 `egfr_12m`，免疫二元 AUROC 到 0.9996。
**決策後的資訊是災難性的，這件事 M0 已經證明過了**，只是入口換成了時間視窗。

程式層面的防護：`src/longitudinal.py` 的所有特徵函式只吃 t ≤ 0 的面板，
`leak_demo()` 保留在原地，等真實資料（有治療反應）進來時重跑。
