## 五、未變更、仍屬限制

- 標籤仍是共存疾病的操作型定義，不是切片病因。
- 單次檢驗，不確認腎臟異常的慢性性（KDIGO 2024 要求至少三個月）。
- 預測模型的血中金屬特徵仍只來自 1999–2004 檢驗檔（其他週期以中位數補入）；外部確認的事後探索顯示這類特徵在新資料上會拖累判別（第六節），下一版以常規套組取代比跨週期合併更合適。
- ~~權重分析只有點估計，未以 PSU／分層估計設計變異。~~ 2026-09-27 已完成（第八節）；仍不含模型重新配適的變異，2021–2023 未用抽血權重 WTPH2YR。
- **HDL 膽固醇被誤排除（2026-09-27 外部確認時發現）**：v3 封存規則為排除 D 型肝炎抗體而用了字首 `LBDHD`／`LBXHD`，把 HDL（1999–2002 `LBDHDL`、2003–2004 `LBXHDD`）一併排除於特徵外。屬過度排除，不造成洩漏；凍結模型不受影響，下一版重訓時改為明列。

## 六、外部確認（NHANES 2021–2023，2026-09-27）

**執行順序**：協定與模型凍結（9ca4e9f）→ 使用者同意後下載 17 檔、大小與凍結紀錄一致 → 評估前資料核對（只含標籤計數與特徵分布）→ **修正一提交（44b0ace）** → 一次評估 → 結果提交（a7c4af8）→ 事後探索。

| 項目 | 內容 |
|---|---|
| 評估前發現 | CDC 2021–2023 更換生化儀器（Cobas 6000→8000）、尿白蛋白改 LC-MS/MS、空腹三酸甘油酯改非甘油空白法並更名 LBXTLG、維生素 D 更名 LBXVIDMS；凍結程式只核對了肌酸酐，照原樣執行會讓兩個更名特徵整欄補中位數，尿白蛋白與十餘項生化值也不在開發量尺上 |
| 修正一規則 | CDC 建議之回推式一律套用（15 項）；滲透壓、Friedewald LDL、ACR 由調整後組成重算；更名者對應回原名；其餘不動；模型、校準、門檻、指標不變 |
| 主要結果（調和後） | 糖尿病 n 1,069、陽性 420：AUROC 0.743（0.712–0.774），截距 0.25、斜率 0.82；肝炎 n 1,032、陽性 11（HBsAg 6、HCV RNA 5）：AUROC 0.718（0.609–0.838），平均預測 2.6% vs 實際 1.1% |
| 事前指定比較 | 常規套組 LR：糖尿病 0.770（較部署高 0.027，配對 CI 0.003–0.052）、肝炎 0.743；梯度提升：糖尿病 0.807、肝炎 0.653 |
| 敏感度（依凍結程式原樣） | 糖尿病 0.764（截距 −0.49、斜率 1.09）、肝炎 0.729；樣本不同（腎臟異常 1,055 vs 1,111） |
| 事後探索（評估後撰寫） | 遮蔽六項開發時只有 1999–2004 有值之非常規特徵：糖尿病 0.743 → 0.769（差 +0.025，0.002–0.051）；肝炎 0.718 → 0.742（−0.022 至 0.070） |
| 解讀 | 糖尿病軸初步確認；肝炎軸事件遠少於外部驗證建議的 100 個，無法確認，且需重新校準；部署建議改用常規套組模型 |
