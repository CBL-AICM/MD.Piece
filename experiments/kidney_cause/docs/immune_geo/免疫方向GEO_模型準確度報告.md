# 免疫方向補強：NIH GEO 腎臟切片轉錄體模型準確度報告

資料：NIH 國家生物技術資訊中心（NCBI）Gene Expression Omnibus 公開之歐洲腎臟 cDNA 庫（ERCB）切片轉錄體，GSE104948（腎絲球）與 GSE104954（腎小管間質）。每例診斷皆經腎臟病理確認。分析計畫 `params/immune_geo_plan.json` 於執行前提交（8cf98d5）；發現批次混淆後之修正一 `params/immune_geo_amendment_1.json` 亦於執行前提交（b051817）。

## 一、結論

1. 在同一處理批次內，免疫性腎病與非免疫腎病在腎臟組織有可區分的分子訊號。ANCA 血管炎對非免疫腎病，免疫路徑模型 AUROC 0.773、全基因模型 0.927；紅斑性狼瘡腎炎對 FSGS，免疫路徑模型 0.938。三項任務皆通過修正一於計算前寫定的判定規則（B2 只有全基因模型通過），且在腎小管間質重現。
2. 唯一能直接比較「免疫對代謝」的是 ANCA 對糖尿病腎病變（22 對 7 例）：全基因模型 AUROC 0.852（95% CI 0.68–1.00），但免疫路徑模型只有 0.594，未達顯著。這表示事前選的六條免疫路徑不足以區分這兩種病，全基因模型的判別力主要來自路徑以外的基因。
3. 狼瘡腎炎的訊號集中在干擾素路徑（單一路徑 AUROC 0.961），高於 1,000 組隨機基因集的第 95 百分位，屬免疫路徑專屬；ANCA 的路徑模型則只在隨機基因集第 87.8 百分位，代表其與非免疫腎病之差異廣泛分布於全基因體，不專屬事前路徑。
4. IgA 腎病變與高血壓腎病變各自只在一個處理批次，同批次內沒有對照，本資料無法評估。
5. 事前計畫原定的主要任務（狼瘡腎炎＋IgA 腎病變對糖尿病＋高血壓腎病變）因診斷與處理批次完全重疊而失效（見第六節），其數字不可引用。

## 六、事前計畫為何失效（照實報告）

GEO 樣本來源名稱中的 H 代碼是處理批次。GPL24120 平台上，糖尿病腎病變全在 H1、高血壓腎病變全在 H2、IgA 腎病變全在 H4、狼瘡腎炎在 H5。事前計畫只注意到兩個晶片平台的混淆，漏看了批次，因此原定任務比較的其實是批次。
徵兆是全基因模型 AUROC 遠低於 0.5：交叉驗證 0.246、保留測試集 0.013，訓練集卻幾乎全對，屬於記憶批次。原計畫判定「回推成立」為否，「免疫路徑專屬」雖為是，但同樣無法解讀。平台陰性對照 AUROC 0.015 被判為通過，是因為門檻只看信賴區間上界；AUROC 遠低於 0.5 同樣代表兩平台可完全分開，平台校正實際上失敗。原結果檔照原樣保留，未刪改。

## 七、限制

1. 這是確診後的切片組織，不是常規抽血驗尿；結果說明免疫性病因在腎臟本身可辨識，以及哪些路徑值得轉成血液或尿液檢驗，不能證明常規檢驗可回推免疫方向。
2. 樣本少（B2 只有 29 例，其中糖尿病腎病變 7 例），信賴區間寬；腎絲球與腎小管間質來自同一批切片，重現不是獨立驗證。
3. 沒有獨立的外部資料集；同批次內仍可能存在未記錄的處理差異。
4. ERCB 的糖尿病腎病變是臨床上需要切片的非典型個案，不代表一般糖尿病腎病變。
5. 沒有感染方向的資料；IgA 腎病變與高血壓腎病變無法評估。
