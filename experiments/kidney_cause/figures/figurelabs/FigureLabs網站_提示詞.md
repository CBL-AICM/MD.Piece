# FigureLabs 網站用提示詞（11 張，一張一則）

用法：
1. 在 chat.figurelabs.ai 用 tpc104130 登入，每張圖開一則新對話。
2. 圖一、圖二選「流程圖」。圖三到圖十一選「圖表」，並上傳下面註明的 CSV（在 `figures/figurelabs/data/`）。
3. 把對應的整段提示詞複製貼上。
4. 產生後下載 PNG，存到 `figures/figurelabs/png/`，檔名照每段標題，例如 `圖三_判別力.png`。
5. 全部下載完交回給 Claude，由 Claude 核對數字並換進文件。

以下每段都包含共同要求，不必另外補充。
