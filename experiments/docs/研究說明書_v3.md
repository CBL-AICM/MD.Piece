## 摘要

腎臟指標異常時，病因評估需要整合病史、共存疾病與多種檢查。本研究提出一個可以被檢驗的問題：**一般健康檢查已有的常規血液與尿液數值，能否提供病因的大概方向？**

以美國國家健康與營養調查（NHANES）1999–2018 年十個週期成人 55,081 人為資料，依官方文件重建檢驗校正，並把腎臟指標與兩個共存標籤（肝炎病毒感染、糖尿病）改為陽性、陰性、未知三值判定。在腎臟指標異常者中建立辨識模型，以巢狀交叉驗證評估判別與校準，並比較簡單基準、時間外推與抽樣設計。重分析過程中發現並更正多項能通過檔案雜湊檢查的資料錯誤。

肝炎軸 AUROC 0.783、糖尿病軸 0.765，只用年齡與性別時僅 0.592 與 0.557；肝炎軸的訊號幾乎全來自 C 型肝炎。以從未參與開發的 NHANES 2021–2023 一次評估：糖尿病軸 0.743，只用常規檢驗的模型為 0.770；肝炎軸只有 11 名陽性，無法確認。據此把網頁工具改為只用常規檢驗，並以新資料重新校準。常規檢驗能提供病因線索，但不等於診斷，也不能用來省略肝炎篩檢。

**關鍵詞**：腎臟指標異常、病因線索、C 型肝炎、糖尿病、預測模型、校準、外部確認

## 壹、研究動機

### 一、一個臨床上的空白

腎臟病的病因評估需要整合病史、共存疾病、用藥、身體檢查、實驗室數據與影像，必要時還需要病理或基因檢查；單次 eGFR 下降或白蛋白尿升高，也不足以確認異常已持續三個月以上[1]。另一方面，多數人每年健康檢查都在抽血、驗尿，這些數值早已存在，卻很少被拿來回答「腎臟為什麼出問題」。

> ⚠️ **待填寫**：此處請補上研究者本人的真實動機（接觸的個案、課堂、新聞或閱讀所見）。本說明書不代寫這一段。

### 二、從「能不能」到「能到什麼程度」

教科書上，不同病因各有典型的血液表現：慢性病毒性肝炎影響肝臟的合成功能，糖尿病改變代謝指標。既然如此，把常規數值交給模型，能不能在其他檢查之前，指出值得優先查證的方向？

本研究最初設計感染、代謝、免疫三類病因。免疫類在公開資料中缺乏補體、自體抗體與病理等關鍵檢驗，無法建立可靠的標籤，因此移除，只保留兩軸。研究者也在分析前立下原則：若假設不成立，就照實報告並找出原因，不為了好看的數字調整方法。

### 三、這一版為什麼要重來

前一版（v2）完成後接受外部方法學審查。審查者指出標籤缺失、跨週期校正、校準流程、抽樣權重與時間驗證等問題，但因沒有資料，只能列為「待執行」。本版以原始資料逐項執行，結果發現了審查者看不到的錯誤：四項資料層級的錯誤都能通過檔案雜湊檢查，其中三項無法從文件看出。這說明「資料是真的」不等於「分析是對的」，也成為本研究最重要的方法學教訓。

## 貳、研究目的

### 主要問題與假設

**H₁**：在腎臟指標異常的成人中，常規血液與尿液檢驗辨識肝炎病毒感染與糖尿病兩個共存標籤的能力，明顯優於只用年齡與性別，而且在從未參與開發的新資料上仍然成立。

判定方式事先寫定：內部表現以巢狀外層評估的 AUROC、平均精確率與校準報告，外部表現以 NHANES 2021–2023 一次評估報告；不以任何固定分數作為通過門檻。

### 具體目的

1. 依 NHANES 官方文件重建腎臟指標與兩個共存標籤，未知不再當作陰性。
2. 以校準與門檻完全留在訓練資料內的巢狀評估，報告兩軸的判別、校準與三段分區表現。
3. 以同一切分比較簡單基準，並檢驗時間外推、調查權重與抽樣設計的變異。
4. 重新檢視上游暴露關聯，在同一批受試者中比較血中與尿中金屬（探索性）。
5. 在取用任何新資料之前凍結外部確認協定，再以 NHANES 2021–2023 一次評估。
6. 依外部結果更新離線網頁工具，並確認網頁與 Python 的計算完全一致。

## 肆、研究過程或方法

### 一、研究架構

1. 下載 NHANES 公開檔，登錄出處帳本。
2. 依官方文件校正肌酸酐，建立腎臟指標與兩個共存標籤的三值判定。
3. 在腎臟指標異常者中，以常規檢驗建立兩軸模型。
4. 以巢狀交叉驗證評估判別、校準與三段分區，並與簡單基準比較。
5. 檢驗時間外推、調查權重與抽樣設計變異。
6. 掃描上游暴露關聯（探索性）。
7. 凍結協定後，以 NHANES 2021–2023 一次外部確認。
8. 依外部結果更新網頁工具，並核對計算。

### 二、分析樣本與三值標籤

納入年齡至少 20 歲者。腎臟指標異常定義為單次 eGFR < 60 mL/min/1.73 m² 或尿白蛋白／肌酸酐比（ACR）≧ 30 mg/g[1]；eGFR 以 CKD-EPI 2021 無種族係數公式計算[2]。每一項判定都分成三種結果：

| 判定 | 陽性 | 陰性 | 未知 |
|---|---|---|---|
| 腎臟指標 | 任一已測指標達門檻 | 兩項皆測且正常 | 一項正常而另一項缺，或兩項皆缺 |
| 肝炎病毒感染 | HBsAg 陽性或 HCV RNA 陽性[3,4] | 兩者皆可排除 | 其餘，例如抗體陽性但沒有 RNA |
| 糖尿病 | 醫師診斷或 HbA1c ≧ 6.5%[5] | 問卷與 HbA1c 皆為陰性 | 拒答、不知道或缺值 |

前一版把「未知」當成「陰性」，讓沒做檢驗的人被算成沒病。本版各軸只排除該軸未知者，兩個標籤可以同時成立。這些標籤是共存疾病，不是腎臟病理；共存不代表腎損傷由它造成，所以本研究稱之為「病因線索」。

### 三、檢驗校正

NHANES 各週期的檢驗方法不同，必須依官方文件換成同一量尺：

- **血清肌酸酐**：1999–2000 年為 1.013 × 原值 ＋ 0.147[6,7]，2005–2006 年為 −0.016 ＋ 0.978 × 原值[8]。前一版在 1999–2000 年誤用了 1988–1994 年的公式。
- **尿肌酸酐**：2007 年起改用酵素法，2007 年前的值依官方分段式轉換[9]。
- **2021–2023 年**：生化儀器與尿白蛋白、三酸甘油酯的檢驗方法都更換了；評估前依 CDC 公布的回推式，把 15 項換回開發時的量尺[10,11,12]（附錄三）。

### 四、特徵與近端特徵消融

特徵為各週期共有的常規血液與尿液檢驗 62 項，含 ACR、eGFR、嗜中性球／淋巴球比、年齡與性別。定義標籤的檢驗一律不作特徵。各軸再移除生理上緊鄰標籤的「近端特徵」：肝炎軸移除 ALT、AST、GGT、總膽紅素，糖尿病軸移除血糖與滲透壓。「常規套組」依是否為一般健檢項目事先定義（肝炎軸 44 項、糖尿病軸 46 項），不看表現挑選。

### 五、模型與巢狀評估

部署模型為邏輯迴歸：先以中位數補缺值、標準化，再以五折交叉配適得到五個模型並平均，最後以保序迴歸校準。評估採分層五折、重複五次的巢狀外層評估：每一折都在該折的訓練資料內重新完成補值、標準化、配適、校準與門檻計算，被評估的人從未參與任何一步[13,14]。

判別以 AUROC 與平均精確率（AP）報告；肝炎軸盛行率低，以 AP 為主要摘要。校準報告校準截距、校準斜率與 Brier 分數[15]。

### 六、三段分區

工具輸出「傾向」「不確定」「不傾向」三區，規則在看到結果前寫定：預測勝算達事前勝算 2 倍以上為傾向，0.5 倍以下為不傾向，相當於概似比 2 與 0.5。常規套組有值不足一半時標示「資料不足」，不給分區。

### 七、比較、時間外推、調查權重與設計變異

- **同切分比較**：只有截距、只用年齡性別、常規套組、全特徵邏輯迴歸、全特徵梯度提升，在同一批外層切分上比較，差值附配對信賴區間。
- **時間外推**：以 1999–2008 年開發、2009–2018 年評估。
- **調查權重與設計變異**：以合併 20 年 MEC 權重計算加權指標[16]；變異依抽樣設計的分層與 PSU，以刪一 PSU 摺刀法估計[17]，比例採 Korn–Graubard 區間[18]。

### 八、決策曲線

決策曲線比較「依模型送驗」「全數送驗」「全不送驗」三種做法的淨效益[19]。肝炎檢驗便宜、無創，且指引建議成人普遍篩檢[3,20]，合理的閾值機率很低。

### 九、暴露關聯（探索性）

以全體成人掃描 213 個暴露與腎臟指標的關聯，以 Benjamini–Hochberg 法控制偽發現率[21]；並在同時有血、尿值的同一批受試者中，比較血中與尿中金屬。

### 十、外部確認

NHANES 2021–2023 年於 2024 年釋出，從未參與任何開發決策。取用前先凍結三個模型與評估規則，並記錄雜湊（提交 9ca4e9f），程式只允許評估一次。取用後、計算任何預測之前，發現檢驗儀器與方法已變更，於是先提交量尺調和的修正（44b0ace）；照凍結程式原樣執行的結果，列為事前指定的比較。

### 十一、網頁工具 v3.1

外部確認後，網頁工具改用常規套組模型，並以 2021–2023 年資料重新校準：事件至少 100 個、且斜率檢定顯著時才同時更新斜率，否則只更新截距[22]。事前機率改為 2021–2023 年的比例，分區門檻依同一規則重算。網頁是單一離線檔案，計算以 Node.js 與 Python 逐軸核對。

糖尿病軸在人口加權下平均預測偏高，區間不含 0：機率不能直接移植到組成不同的人群。

### 五、決策曲線：判別力不等於決策效用

![](../kidney_cause/figures/v3/圖5_決策曲線.png)

**圖5　決策曲線。** 閾值機率須由實際檢驗的利弊決定。

肝炎軸在閾值 0.5% 時，依模型送驗與全數送驗的淨效益幾乎相同（0.5%：模型 0.0148、全數送驗 0.0146）。若只略過「不傾向」區，每千人送驗 449 人、漏掉 3.7 名陽性，占陽性 19%。**因此本工具不能用來決定誰可以不驗肝炎。**

### 六、暴露關聯（目的四，探索性）

![](../kidney_cause/figures/v3/圖6_暴露血尿比較.png)

**圖6　同一批受試者之血中與尿中鉛、鎘。** 勝算比為濃度加倍。

213 個暴露中 26 個通過偽發現率 0.05。藥物關聯與處方常規一致，例如腎功能差時應停用的雙胍類呈負相關，可由適應症與反向因果解釋，不能當作致病證據。前一版「血中升、尿中降就是反向因果的直接證據」，建立在沒有共同受試者的比較上，本版已撤回；在同一批 11,625 人中，尿中金屬的方向取決於結果定義與寫法。

## 陸、討論

### 一、假設的成立範圍

H₁ 在糖尿病軸成立：內部 AUROC 0.765、外部 0.743，都明顯高於只用年齡性別的 0.557。肝炎軸的內部結果支持 H₁（0.783 對 0.592），但外部只有 11 名陽性，尚不能確認。因此 H₁ **部分成立**。

### 二、肝炎軸其實是 C 型肝炎軸

C 型肝炎標籤者的血液型態一致：球蛋白較高（單變量 AUROC 0.771）、白蛋白較低（0.349）、血小板與總膽固醇較低（0.368、0.376），與慢性病毒性肝炎之血脂研究方向一致[24]。B 型肝炎帶原者的常規檢驗大多接近正常，單變量掃描 51 個標記只有 1 個通過偽發現率校正。2021–2023 年的陽性組成偏向 B 型，正好落在工具的弱點上。

### 三、雜湊抓不到的錯誤

本研究最重要的方法學教訓是：資料來源正確，不等於分析正確。以下四項錯誤都能通過 SHA256 檢查：

| 錯誤 | 後果 | 更正後 |
|---|---|---|
| 1999–2000 年肌酸酐用錯公式 | 該週期腎功能下降被少算 | eGFR < 60 由 86 人增為 340 人 |
| 2003–2004 年沒有 HCV RNA 變數，抗體陽性者被判為陰性 | 肝炎陽性被低估 | 改判為未知 |
| 沒做檢驗的人被當成陰性 | 陰性組混入未受檢者 | 三值判定；腎臟結果可判定由 51,792 人改為 48,962 人 |
| 血中與尿中金屬合併時欄位撞名 | 血尿比較其實不是同一批人 | 在同一批 11,625 人中重新比較 |

外部確認前也發現，CDC 更換了檢驗儀器與方法；若照凍結程式原樣執行，兩個特徵會整欄被當成缺值。這些錯誤都不會讓程式當掉，只會安靜地產生看似合理的數字。

### 四、作為病因線索的意義與界線

本研究的核心問題是「找原因」。現有資料能支持的結論是：當常規檢驗呈現與 C 型肝炎或糖尿病相符的型態時，這組數值提供「值得優先查證這兩個候選病因」的線索，而且附有可追溯的推動因子與經校準的機率。它不能回答腎損傷是否由該病造成；免疫性病因在 NHANES 缺乏補體、自體抗體與病理，仍無法評估[25]。在臨床行動上，肝炎檢驗應依普遍篩檢建議進行，本工具的角色是解釋與排序，不是省略檢驗。

### 五、與文獻之比較

- 腎臟病病因評估需要整合多種資訊，單次異常也不代表慢性[1]；本研究因此只宣稱「病因線索」。
- 預測模型的報告與偏誤評估參照 TRIPOD+AI 與 PROBAST+AI[13,14]。
- 外部驗證一般建議至少約 100 個事件[23]；本研究肝炎軸外部只有 11 個，照實標示為未確認。
- 慢性病毒性肝炎與血脂異常的關聯[24]，與本研究觀察到的 C 型肝炎型態方向一致。

### 六、創新點

1. **把「找原因」拆成可檢驗的問題**：以共存標籤評估常規檢驗的病因線索，並清楚區分線索與診斷。
2. **可重現的防自欺流程**：出處帳本、先提交後執行、外部資料只評一次、網頁與 Python 逐軸核對。
3. **在公開資料中找出雜湊抓不到的錯誤**，並公開更正前後的差異。
4. **完整的外部確認**：評估前依官方回推式調和檢驗量尺，同時報告照原樣執行的結果。
5. **兼顧抽樣設計**：以 PSU 與分層估計加權指標的設計變異。

### 七、研究限制

1. 標籤為共存疾病的操作型定義，不是腎臟病理；單次檢驗不確認慢性。
2. 1999–2018 年資料已在前一版反覆使用，本版內部結果屬探索性；確認性證據來自 2021–2023 年外部資料。
3. 肝炎軸陽性事件少，外部只有 11 個，肝炎軸的外部表現仍未確認。
4. 預測視為固定，設計變異不含模型重新配適的變異；2021–2023 年未使用抽血權重。
5. 部分非常規特徵只在 1999–2004 年有值；開發時 HDL 膽固醇因變數字首規則被誤排除，將於下一版修正。
6. 暴露分析為單次橫斷面，無法建立時序；美國調查的機率也不能直接移植到臺灣的就醫族群。

### 八、未來展望

| 階段 | 目標 | 資料 | 狀態 |
|---|---|---|---|

### 九、對臨床的貢獻與不做的事

| 貢獻 | 邊界 |
|---|---|
| 不需新檢驗的病因線索：只用常規項目，輸出方向與推動因子 | 共存標籤不是病理；輸出是線索，不是診斷 |
| 「不能拿來省略篩檢」的明確界線：肝炎軸在低閾值時與全數送驗相同 | 適用於確診檢驗便宜、無創的情境 |

| 可移植的防自欺流程 | 只擋得住已知的陷阱 |

本研究不取代切片、不輸出診斷、不給治療建議。

## 柒、結論

1. 常規血液與尿液檢驗對腎臟指標異常成人中的糖尿病標籤，有中等且校準良好的辨識力，並在 2021–2023 年新資料上大致維持。
2. 肝炎軸的訊號幾乎全來自 C 型肝炎；對 B 型肝炎幾乎沒有訊號，外部事件太少而無法確認。
3. 只用常規檢驗的模型不輸全特徵模型，網頁工具因此改為常規套組並重新校準。
4. 本工具提供的是病因線索，不是診斷，也不能用來省略肝炎篩檢。
5. 資料來源正確不等於分析正確；本研究找到並更正了多項能通過雜湊檢查的資料錯誤。

#### （四）名詞說明

| 名詞 | 說明 |
|---|---|
| AUROC | 隨機取一名陽性與一名陰性，模型給陽性較高分的機率；0.5 等於亂猜，1 為完美 |
| 平均精確率（AP） | 依分數由高到低篩選時的平均精確率；盛行率低時比 AUROC 更能反映實用性，應與盛行率並列 |
| 校準 | 預測機率與實際比例是否一致；校準斜率 1、截距 0 最理想 |
| 巢狀交叉驗證 | 把資料分成數折，每一折的補值、配適、校準與門檻都只用其他折完成，再評估這一折 |
| 概似比 | 檢驗結果使事前勝算放大或縮小的倍數；本工具以 2 與 0.5 分區 |
| PSU 與分層 | NHANES 先把全國分層，再在每層抽出地區單位（PSU）；估計變異時必須考慮這個結構 |
| 設計效應 | 考慮抽樣設計後的變異，除以簡單隨機抽樣的變異 |
| 偽發現率 | 多重比較時，被判為顯著者之中偽陽性的預期比例 |
| 共存標籤 | 同時存在的疾病標籤；共存不代表是腎損傷的原因 |
