## 壹、研究概要

| 項目 | 內容 |
|---|---|
| 題目 | 血液會說話嗎？以常規檢驗回推腎炎（腎損傷）的病因方向 |
| 核心問題 | 只用一般健檢的常規抽血、驗尿，能否回推腎炎（腎損傷）的病因方向——感染、代謝、免疫 |
| 延伸問題（10-08 起） | 已知有腎損傷，可能是哪一個方向的哪一種病、為什麼（代謝、免疫、感染各三病） |
| 腎損傷之操作型定義 | eGFR<60（CKD-EPI 2021）或尿白蛋白／肌酸酐比 ≥30 mg/g（NHANES 沒有腎炎診斷） |
| 資料 | 美國國家健康與營養調查（NHANES）公開、已去識別資料：開發 268 檔（1999–2018）、外部確認 17 檔（2021–2023），共 285 檔、401 MB；每檔記錄網址與 SHA256，未登錄者程式拒跑 |
| 研究倫理 | 只使用公開、已去識別資料（09-28 使用者決定，刪除所有需倫理審查之內容） |
| 主要方法 | 三值標籤（陽性／陰性／未知）；巢狀交叉驗證（5 折×5 次）；時間外推；外部確認只評一次；PSU 與分層之設計變異；所有新分析先提交計畫與程式、後計算 |
| 目前結論 | 代謝方向可回推：糖尿病軸常規套組邏輯迴歸 AUROC 0.761、梯度提升 0.821（只用年齡性別 0.557）；感染方向只能部分回推：肝炎軸 0.807，訊號主要來自 C 型肝炎（0.849；B 型 0.686）；免疫方向回推不了：抗核抗體代理標籤 0.546，未優於年齡性別 0.596。回推的是方向，不是確診 |
| 九種病因（10-09） | 腎損傷成人之調整盛行率比：糖尿病 2.68（2.50–2.87）、痛風 2.18（1.87–2.54）、HIV 2.03（1.29–3.19）、高尿酸血症 1.99（1.89–2.10）、C 型肝炎 1.44（1.09–1.89）、肥胖 1.31（1.26–1.37）；B 型肝炎 1.35（0.85–2.16） 無法區分；七項皆與事前寫下之文獻預期一致。紅斑性狼瘡、IgA 腎病變、ANCA 相關血管炎於 NHANES 量不到，只做文獻回顧（73 篇，PubMed 核對） |

## 貳、研究歷程

### 一、建置與第一版（2026-08-30）

1. 使用者的初始要求：只用真實資料、不得虛擬資料，建立感染／免疫／代謝三類病因模型，全範圍找未知標記，AUROC 達 0.90，並以腎超音波佐證。0.90 之後一直未達到，自此只並列實際值、不以 0.90 調整模型；超音波佐證於 09-28 刪除（只用公開資料）。
2. 建立真實資料出處帳本（每個檔案的網址、SHA256、大小、下載時間；未登錄或雜湊不符即拒跑）與設計參數檔（標籤規則事前鎖定），提交 5738bcc。
3. 第一版（v1，d5a16da）：NHANES 1999–2004 三個週期，三類互斥標籤；AUROC 免疫 0.812、感染 0.873、代謝 0.832，皆未達 0.90。

### 二、自我修正與擴充樣本（2026-08-30～08-31）

1. 同一天內找出三個高估：免疫標籤把未做抗核抗體的人當成陰性（修正後 0.812 → 0.584）；三類互斥在 NHANES 的結構上無解，改為二元任務；代謝 0.913 是血糖洩漏（拔除後 0.814；325555e、c434c1e）。
2. 擴充至 1999–2018 十個週期（4cf0dcf、e4ab5c0）：腎損傷 8,983 人；感染類 AUROC 各下降 0.057、信賴區間收窄約一半。擴充樣本的價值是揭露小樣本的樂觀，不是推高分數。
3. 找到程式靜默丟資料：2001–2002 年肌酸酐變數名為 LBDSCR，整個週期曾被丟棄（9f7156a）。
4. 最終模型（肝炎單軸決策規則，四項事前條件）：開發集四項全過，保留集只過兩項；原因是 ROC 在敏感度 0.80 處陡降（87d455c）。同時更正「AUPRC 提升 6.7 倍」：在實際作業點上精確度只提升 1.8 倍。保留集已評兩次，此後不再宣稱一次性保留集。
5. 上游暴露掃描（ExWAS，全體成人 213 項暴露）：24 項 FDR<0.05，但沒有一項站得住因果——同一元素血中升高、尿中降低，護腎藥與須停用之雙胍方向相反，反映的是腎臟排泄與處方行為（64f0f13）。過程中修正兩個程式錯誤：尿肌酸酐被當成暴露（a789d8f）、二元暴露被誤砍（da1b046）。另建孟德爾隨機化核心（5e87aaa），因金屬之基因研究樣本太小而未採用。
