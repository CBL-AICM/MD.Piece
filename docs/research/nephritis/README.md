## 兩條線，一個研究

這份研究目前有兩條並行的線，**它們的架構並不一致**：

| | 計畫／文獻線 | 程式線 |
|---|---|---|
| 在哪 | 本目錄（源自 Obsidian vault） | `experiments/nephritis_attribution/`（PR #606） |
| 現行架構 | v9 排除式級聯 G0–G5 | 兩層架構 ＋ 五層管線 L1–L5 |
| 資料 | CGRD 真實世代（待 IRB） | 合成世代 n=6000 |
| 狀態 | v9 已定案，待改寫 v10 | 六道閘門全過，因 7 項待裁決維持 draft |

兩者共用「固定負載矩陣 ＋ 非負最小平方 ＋ 只用非對角」這組方法，但**作用在不同的統計量上**，
而且狼瘡的角色、C4 的方向、共變異數的層級三處實質衝突。
依鐵則 7（衝突要攤開講，禁止混合寫法），這裡不做平均，完整攤開在
[兩條主線的落差](00_整合重點/兩條主線的落差.md)，並附一個明確的收斂建議與需要裁決的問題。
