# 決策 002：負載矩陣必須由文獻固定

## 決策

放棄探索式因子分析，改為**驗證式分解**：負載矩陣由文獻固定，只以非負最小平方解各驅動變異。

## 依據（數值否證）

自由估計負載時，主導驅動判對率在所有樣本量下等於亂猜（32–37%，亂猜 33%），即使 N ＝ 120 亦然。原因是 [旋轉不確定性](../05_%E6%A6%82%E5%BF%B5%E7%AD%86%E8%A8%98/%E6%97%8B%E8%BD%89%E4%B8%8D%E7%A2%BA%E5%AE%9A%E6%80%A7.md)——「哪個因子是免疫、哪個是代謝」在數學上沒有被定義，樣本無限大也不會改善。

改為驗證式後：N ＝ 20 → 56%、N ＝ 60 → 61%、N ＝ 120 → 66%。

## 最重要的後果

**[負載矩陣](../05_%E6%A6%82%E5%BF%B5%E7%AD%86%E8%A8%98/%E8%B2%A0%E8%BC%89%E7%9F%A9%E9%99%A3.md) 的文獻錨定從「最好要有」變成「沒有就數學上必然失效」——成為全案的存亡前提。**

## 附帶作業禁令

任何情況下不得逐人標準化（破壞 [誤差免疫](../05_%E6%A6%82%E5%BF%B5%E7%AD%86%E8%A8%98/%E8%AA%A4%E5%B7%AE%E5%85%8D%E7%96%AB.md)），須有執行期斷言。
