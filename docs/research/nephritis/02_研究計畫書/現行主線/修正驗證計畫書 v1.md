## 零、本文件的用途

前一份分析文件指出研究方向由「預後」轉為「診斷」後產生的十項邏輯漏洞。本文件把每一項漏洞轉成一個可執行的修正動作與一個可判定的驗證方式，並排出執行順序。

**核心原則**：先做能一票否決整個研究的檢查，再投入其他工作。目前有兩項假設承重卻完全沒有實證支持（負載向量的疾病特異性、資料前提的現實可得性），必須優先處理；在它們回答之前撰寫 v7 計畫書會白寫。

## 參、標籤定義：岔路口的決議

這是全案第一個必須做的決定，因為底下每一節都取決於它。

### 兩個選項

| 案 | 標籤 | 優點 | 缺點 |
|---|---|---|---|
| 甲 | **組織單獨可判定之型態**（免疫螢光沉積型態、電顯沉積位置） | 不循環；病理科可獨立判定 | 可能只是重述切片結果，臨床價值需另行論證 |
| 乙 | 臨床整合之病因診斷（如「狼瘡腎炎 class IV」） | 臨床有用 | 標籤本身由預測通道推導，循環無法以拿掉通道修復 |

### 決議

**主要分析採甲案，次要分析採乙案並明白承認循環性。**

理由：乙案的循環性是結構性的，無論做多少敏感度分析都無法消除，若以它為主要結局，整份研究的核心發現會被單一質疑推翻。甲案雖然臨床價值需另外論證，但它的結論站得住。

### 分類草案（**待病理科主持人確認，本表為草案不得逕用**）

| 類 | 組織判準（僅用組織資訊） | 對應之常見病因 |
|---|---|---|
| T1 | 繫膜區以 IgA 為主之沉積 | IgA 腎病變 |
| T2 | 上皮下沉積為主，無增生 | 膜性腎病變（原發或次發） |
| T3 | 免疫複合物增生型，含 full-house 型態 | 狼瘡腎炎、感染後、其他次發 |
| T4 | 寡免疫型（免疫螢光染色微弱） | ANCA 相關血管炎 |
| T5 | 非免疫複合物之硬化或基底膜病變 | 糖尿病腎病變、局部節段性硬化 |
| T6 | 兩類以上並存 | 混合病因 |

**注意 T3 的性質**：T3 不等於狼瘡腎炎——這正是漏洞二的核心。研究要問的是「T3 之內，能否再分出狼瘡與非狼瘡」，而這一步必然需要臨床資訊，故列為次要分析並承認循環。Sciascia 2025 那 5 位特發性 full-house 病人即屬 T3 中的非狼瘡者。

### 輸出型態的決議

主要設計為**狼瘡之排除試驗**：二元、以狼瘡為陽性、門檻鎖在高敏感度、主要指標為陰性預測值與可免除比例。理由是它接得上既有的錯誤代價不對稱論述與 Chedid 2020 的缺口，且統計上比多類別容易達到可用強度。多類別鑑別清單列為次要結局。

## 肆、數值驗證的兩項新結果（影響設計）

### 一、秩一殘差 R 在小樣本下不可用（重要更正）

前一份文件以充足樣本（2,000 點）顯示單一潛在過程之 R ＝ 0.022、兩個過程 ＝ 0.297，據此提出公式三′ 可偵測混合病因。**加做小樣本檢驗後，此結論必須大幅限縮**：

| 同日成套次數 N | 虛無中位 R | 虛無 95 百分位 | 混合病因中位 R | 區辨 AUC |
|---|---|---|---|---|
| 12 | 0.343 | 1.078 | 0.362 | **0.501** |
| 20 | 0.317 | 1.156 | 0.351 | 0.541 |
| 34 | 0.235 | 0.956 | 0.361 | 0.627 |
| 60 | 0.188 | 0.739 | 0.366 | **0.718** |
| 120 | 0.149 | 0.446 | 0.353 | 0.835 |
| 2000 | 0.035 | 0.115 | 0.331 | 1.000 |

**判定**：N ＜ 34 時 R 完全無法區辨（AUC ≈ 0.50），因為抽樣雜訊本身產生的殘差已與真實混合病因同量級。公式三′ 因此**降為條件性使用**：僅在 N ≥ 60 之子群啟用，且必須附虛無分布之百分位而非絕對門檻。

此更正必須寫入 v7，不得沿用前一份文件未加限定的說法。

### 二、逐人標準化會破壞[誤差免疫](../../05_%E6%A6%82%E5%BF%B5%E7%AD%86%E8%A8%98/%E8%AA%A4%E5%B7%AE%E5%85%8D%E7%96%AB.md)（作業禁令）

若對每位病人各通道做 z 轉換，則 l′_k ＝ l_k ／ √(l_k²·Var(x) ＋ σ_k²)，比例 l′_a/l′_b **重新含有 σ**，誤差免疫性質失效；跨病人比較因各人 σ 不同而不可比。模擬中真值 1.667 之估計由 1.267 變為 1.893，方向不定。

**作業禁令**：標準化只能以**全世代分布**為基準（此為各通道固定之線性重參數化，對所有病人一致，不破壞可比性）；**任何情況下不得逐人標準化**。此條列入品質關卡。

## 伍、模型建置作業（可照著做）

### 一、特徵計算：逐人八步

| 步 | 動作 | 規則與注意事項 |
|---|---|---|
| 1 | 界定觀察窗 | 主要：切片日前 365 天。敏感度：180、730 天 |
| 2 | 找出同日成套組 | 嚴格定義：同一就診序號且採檢時間戳差 ≤ 4 小時；無時間戳退為同日曆日（標記等級） |
| 3 | 方向調和 | C3、C4 乘以 −1，使所有通道上升皆代表腎臟活動上升 |
| 4 | 標準化 | **僅用全世代分布**之中位數與中位數絕對離差；**禁止逐人標準化**（肆之二） |
| 5 | 變異門檻檢查 | 若某通道於窗內之穩健變異低於門檻，該通道標記為不可估計，不進入配對；全部不可估計者列入「無訊號組」 |
| 6 | 算共變異數矩陣 | 只保留**非對角元素**；對角線含化驗誤差，一律不使用 |
| 7 | 負載比例與指紋向量 | 對每對 (a,b)，以所有合格第三通道 c 計算 C_ac／C_bc，取**中位數**（穩健）。選最常有且最穩定之通道為參考（建議 UPCR 或肌酸酐），得 f ＝ (l₂/l₁, …, l_K/l₁) |
| 8 | 次要特徵 | 節奏 λ（多個 Δ，取長 Δ 較穩）；領先落後不對稱 A_ab(Δ)；秩一殘差 R（**僅 N ≥ 60 啟用**）；並記錄成套次數 N 與可用配對數，兩者列為共變項與分層變項 |

### 二、必須建立的四個模型

| 模型 | 內容 | 角色 |
|---|---|---|
| M0 洩漏基準 | **只用「哪些檢驗被開立」之指示變數** | 洩漏上界。主模型未顯著超越 M0，即不得宣稱有生理訊號（漏洞三） |
| M1 單點基準 | 切片前最後一次各通道數值之多變量迴歸 | Chedid 2020 已證明其失效，此為要超越的臨床基準 |
| M2 指紋主模型 | f ＋ 節奏 ＋ 領先落後（＋ R，若 N 足） | 主分析 |
| M3 純結構模型 | M2 但排除疾病特異血清學（抗 PLA2R、ANCA 等） | 檢驗「不靠既有特異標記還剩多少」，對應主要主張 |

分類器建議用正則化邏輯迴歸：可解釋、樣本效率高、係數方向可與文獻錨定之負載型態對照。非線性方法僅列為次要且須報告可解釋性代價。

### 三、驗證分割

| 項目 | 規則 |
|---|---|
| 開發與驗證 | 較早年份開發、較晚年份時間外驗證；同一病人所有紀錄必須在同一分割 |
| 閾值鎖定 | 所有超參數、門檻於驗證前鎖定，測試集不參與任何選擇 |
| 外部驗證 | 跨院區（台北／林口）互為外部；單一院區之隨機分割不稱外部驗證 |
| 盲性 | 病理判讀不得知悉模型輸出；資料抽取時病理欄位與檢驗欄位分開處理 |

## 陸、三層驗證架構

### 層一：合成資料（驗證公式本身）

| 項目 | 內容 |
|---|---|
| 目的 | 確認公式在已知答案下正確、找出可辨識邊界 |
| 生成器 | 五類病因 × 各自負載向量與節奏 ＋ 混合病因類 ＋ 純雜訊對照 |
| 必測軸 | 成套次數 N、化驗誤差大小、通道數 K、窗長、病情變異幅度 |
| 已完成 | 誤差免疫性質成立（估計誤差 < 10%，對照用對角線錯 > 50%）；分類 AUC 隨 N 上升（N=12 → 0.79、34 → 0.87、60 → 0.92）；R 之小樣本限制（肆之一） |
| 進入層二條件 | 通過零信號檢查（虛無情境回到 0.50）、無洩漏、可辨識地圖完整 |

### 層二：文獻錨定後重跑（驗證假設的現實性）

| 項目 | 內容 |
|---|---|
| 目的 | 用真實疾病的通道型態取代自訂負載向量 |
| 動作 | 逐病抽取各通道之典型方向與相對幅度，建錨定表 |
| **判定點（一票否決）** | 若文獻顯示各病因之負載型態差異遠小於層一設定，或同一病之不同型態差異大於跨病差異（漏洞一），則類別定義須重訂或全案改為描述性研究 |
| 進入層三條件 | 錨定後之可分性仍達事前判準 |

### 層三：CGRD 真實驗證

| 步 | 動作 | 判定點 |
|---|---|---|
| 1 | 第一階段彙總計數（見柒章） | 三個門檻，任一不過即降級 |
| 2 | 世代描述與「序列不足組」對照 | 兩組特徵完整報告，不得只報可分析組 |
| 3 | 建 M0 洩漏基準 | **先建 M0**，取得洩漏上界後才准看 M2 |
| 4 | M1 單點基準 | 預期接近失效（Chedid） |
| 5 | M2 主模型與 M3 純結構模型 | M2 > M0 且 M2 > M1，信賴區間下界大於零 |
| 6 | 排除試驗指標 | 敏感度鎖定下之陰性預測值與可免除比例 |
| 7 | 敏感度分析 | 見柒章清單 |

**執行順序的紀律**：M0 必須先建。若先看 M2 的漂亮數字再回頭建 M0，會有強烈動機去解釋為何洩漏不算數。

## 柒、判定門檻與敏感度分析

### 第一階段彙總計數要問的三個數字

| # | 問題 | 判定 |
|---|---|---|
| 1 | 切片病人中，切片前 12 個月有 ≥ 8 次同日多通道成套者占多少 | 占比過低（例如 < 20%）則放寬窗至 24 個月，仍不足則全案降為描述性可行性研究 |
| 2 | 各檢驗項目於切片前之開立比例（依最終病理診斷分層） | 若開立比例在各診斷間差異極大，洩漏風險高，M0 之角色更關鍵 |
| 3 | 各組織型態類別（T1–T6）之件數 | 依二元排除試驗設計，狼瘡類與非狼瘡類各需足夠件數（依每變項事件數 ≥ 10 之規則，特徵約 10–15 項時各需約 150 例）；不足之類別併入「其他」 |

### 事前指定之敏感度分析
