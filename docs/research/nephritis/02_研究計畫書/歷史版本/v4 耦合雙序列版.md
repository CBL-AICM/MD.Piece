# 紅斑性狼瘡腎臟受累的早期偵測

## 以全身與腎臟兩條序列的耦合關係判斷切片時機：一項模擬可行性研究

**版本** v4（取代 v3 之研究對象與結局設定；方法骨架沿用 v3）
**日期** 2026-08-22　**文獻查證** PubMed，2026-08-22
**研究定位** 方法學可行性與辨識邊界研究，不構成臨床治療建議
**本次範圍** 僅第一階段（機制式模擬）。第二、三階段為未來工作。

---

## 摘要

紅斑性狼瘡的腎臟受累多發生於病程早期，而目前決定何時進行腎切片，主要依賴尿液蛋白量跨過門檻。問題是門檻被跨過時，組織學上的損傷往往已經開始，而現行的常規指標——蛋白尿、補體、抗雙股DNA抗體、血清肌酸酐——被指出無法充分預測腎臟受累的發生。

本研究提出一項可驗證但尚未證實的假說：腎臟受累是一次狀態轉變，其驅動力來自全身性免疫活動；若此轉變前存在系統穩定性的漸進喪失，則全身活動度序列與腎臟指標序列之間的**耦合關係**會先於蛋白尿門檻發生可偵測的改變。

與 v3 的關鍵差異在於觀測設計：v3 僅觀測單一序列，導致雜訊強度與恢復速度在數學上不可分離，模擬結果顯示所有格點都無法區分真訊號與變異度假象。本版同時觀測驅動序列與被驅動序列，提供了分離兩者所需的第二條方程式。

交付物為一份可行性檢核工具：輸入回診頻率、檢驗項目與量測誤差，回答在此監測條件下，腎臟受累的早期訊號是否可辨識，以及可提前多久。

---

## 壹、研究動機

### 一、時機問題

腎臟受累通常在發病後最初數年內發生，臨床上以定期尿液檢查與蛋白尿定量來偵測。也就是說，現行的偵測方式是等待一個量跨過門檻。

但門檻是結果不是過程。等到蛋白尿明顯升高才安排切片，組織學上的變化早已發生，而腎元的損失不可逆。

### 二、現行指標的不足

在幼年型紅斑性狼瘡的回顧中明確指出：現有的常規疾病活動指標——蛋白尿、補體、抗雙股DNA抗體與血清肌酸酐——**無法充分預測腎臟發作**；並指出若能改善偵測腎炎發生的方法，將可提早治療，可能避免不可逆的腎臟疤痕化與腎功能下降。

這段話界定的正是本研究要處理的缺口。

### 三、賭注最大的是年輕族群

同一份回顧指出，幼年發病者有超過八成會出現腎臟受累，成人發病者約四成；而幼年型腎炎病患中，最高可達四成四在成年早期進展至腎衰竭。

台灣的全國性資料方向一致：新診斷紅斑性狼瘡病人中約 2.5% 至 4.9% 於六至八年內進展至末期腎病，且**年輕反而是危險因子**；四十歲以下者在進入末期腎病後的死亡風險，高於同齡非狼瘡的末期腎病病人。

### 四、必須寫進動機的反面證據

「無症狀狼瘡腎炎」確實存在：臨床上沒有腎臟表現的病人接受切片，仍可見組織學病灶，文獻回顧的 193 例中有 30 例為瀰漫增生型。

但同一研究的長期結局是好的——腎臟存活率 98%、病患存活率 91%，末期腎衰竭罕見，與組織學分類無關；作者結論為無症狀狼瘡腎炎的預後主要取決於腎外因素。

**這對本研究是不利證據，必須放在動機裡而非藏在限制裡。** 它的意思是：早一點發現不必然等於早一點該治療。因此本研究的目標不是主張所有人都該提早切片，而是界定「若要提早，訊號在什麼條件下看得見」，並把是否值得提早留給臨床證據回答。須注意該研究發表於 1996 年，其後治療方式已有相當變化。

## 貳、研究問題與假說

### 一、核心問題

在蛋白尿跨過切片指徵門檻之前，全身活動度與腎臟指標之間的耦合關係，是否出現可偵測的改變；若有，在什麼監測條件下看得見。

### 二、機制假設

以雙穩態系統描述腎臟狀態 x：未受累與受累各為一個穩定狀態。
控制參數 μ 由全身性免疫活動驅動：

　　dx = (1/τx)[−x³ + x + μ(t)]dt + 有色雜訊

　　μ(t) = a · u(t) + μ個體

其中 u(t) 為全身活動度（補體、抗雙股DNA抗體等指標所反映），**可觀測**；
μ個體 為個體易感度，不可觀測。

系統越接近轉變邊緣，對 u(t) 變動的反應越大且恢復越慢。
因此可偵測的量不是單一序列的自相關，而是 **x 對 u 的反應強度與反應時間**。

### 三、這一版為何改變觀測設計

v3 僅觀測腎臟序列。在該設定下穩態變異度約正比於雜訊強度與鬆弛時間的乘積，兩者無法從單一被動序列分離。模擬結果證實了這一點：96 個格點中，區辨「真穩定性喪失」與「單純雜訊放大」的 AUC 全部低於 0.50，中位僅 0.28，且加密取樣與提高精度均無改善。

同時觀測驅動序列 u(t) 與被驅動序列 x(t)，提供了分離所需的第二條方程式。這是本版設計變更的唯一理由，也是主要待驗證之處。

### 四、事前假說

| 編號 | 假說 | 可被否證的預測 |
|---|---|---|
| H1 | 耦合式指標（x 對 u 的反應強度與恢復時間）對真轉變的區辨力，顯著優於單序列指標 | 在相同格點下，耦合式指標對「雜訊放大」對照組的 AUC 高於 0.50 且優於單序列版本 |
| H2 | 訊號可辨識性由回診頻率、檢驗項目組合、量測誤差與系統鬆弛時間共同決定，並存在明確邊界 | 存在可重現的邊界；超出後增加頻率或精度不再改善 |
| H3 | 耦合式指標可在蛋白尿跨過切片門檻前提供可用之提前期 | 於固定假警報負擔下，提前期分布之中位數顯著大於零 |
| H4 | 對非轉變機制（雜訊放大、外生衝擊、連續惡化、症狀驅動取樣）仍有假陽性，但其比例可被量化並控制 | 各機制之假陽性率可估計且在事前設定的負擔內 |

**本研究不事前假定** 耦合式指標必然優於單序列指標。v3 的陰性結果已證明此類直覺不可靠。

## 參、對應的臨床行動

本研究的輸出對應**切片時機**這一個決定，不對應其他任何決定。

| 對應 | 不對應 |
|---|---|
| 誰值得在達到常規門檻前接受腎切片評估 | 是否該開始治療 |
| 誰可以延後或免除切片評估 | 用哪一種藥 |
| 監測密度如何分配 | 是否該減藥或停藥 |

選擇切片時機作為對應行動的理由是錯誤代價不對稱：假陽性的代價是一次不必要的評估，假陰性的代價是延誤診斷與不可逆的腎元流失。此不對稱使得中等強度的訊號在此決定上仍可能有用，而在治療決定上則遠遠不足。

## 肆、方法（沿用 v3，僅列變更處）

完整方法見 v3 計畫書。以下僅列本版之變更。

| 項目 | v3 | v4 |
|---|---|---|
| 研究對象 | 已確診腎炎、正在減藥者 | 尚未達腎炎診斷門檻之狼瘡病人 |
| 控制參數來源 | 減藥排程 g(t)，已知且單調 | 全身活動度 u(t)，可觀測但起伏 |
| 觀測序列 | 單一（腎臟活動度） | 雙序列（全身活動度＋腎臟指標） |
| 主要指標 | 滾動自相關與變異度 | x 對 u 的反應強度與恢復時間；單序列指標作為對照 |
| 結局 | 腎炎發作 | 跨越切片指徵門檻 |
| 對應行動 | 監測密度 | 切片時機 |

**保留不變**：六種競爭生成機制、固定假警報負擔、地標式評分（避免反覆評估之多重比較）、有色雜訊、兩型起點重疊、開發與驗證分隔、陰性結果照實報告、三階段證據等級與停止條件。

**新增競爭機制**：全身活動度波動但腎臟未被捲入者。此為本版最重要的虛無對照——它會使 u(t) 與 x(t) 同時波動，卻不代表狀態轉變。

## 伍、預期產出

1. 一張可辨識地圖：以回診頻率、檢驗項目組合、量測誤差為軸。
2. 耦合式指標與單序列指標的直接比較，含 v3 陰性結果作為基準。
3. 各競爭機制的假陽性率清單。
4. 一份可行性檢核工具：輸入監測條件，輸出可辨識與否及可提前多久。
5. 若不可辨識，則為方法的失敗邊界，同樣照實報告。

## 陸、限制與不宣稱事項

| 不宣稱 | 理由 |
|---|---|
| 雙穩態轉變已是腎臟受累的真實機制 | 現階段為可驗證的理論假說 |
| 提早偵測必然改善結局 | 無症狀狼瘡腎炎的長期預後良好，早期發現不等於應早期治療 |
| 可取代腎切片 | 至多為調整切片時機，兩者非同一等級之主張 |
| 任何絕對提前天數 | 由模擬設定決定 |
| 可用於個人決策 | 未完成外部驗證與臨床效益評估 |

其他限制：尚未達腎炎門檻者的回診較疏，資料密度可能不足；全身活動度為起伏而非單調漂移，使「緩慢掃過臨界」的前提弱於減藥情境；四項參數缺口尚未補齊。

**範圍聲明**：本研究之分析對象為程式生成之合成序列，參數取自已發表文獻之彙總統計。全程未招募受試者、未使用個人層級健康紀錄，不構成人體研究。所有結果均為模擬設定下之相對比較。本系統不做診斷，不取代醫師判斷。
