## 壹、新題目定位

### 一、題目怎麼變了

| 面向 | 舊題（v6） | 新題（本文建議之 v7） |
|---|---|---|
| 起點 | 確診 SLE、腎臟乾淨 | **已知有腎炎**（腎絲球疾病已存在） |
| 問題 | 之後會不會走向腎炎、誰該提早切片 | **這個腎炎是什麼造成的**；狼瘡是其中一個待排除的候選 |
| 統計對象 | 預後（時間到事件） | **診斷（分類）** |
| 參考標準 | 腎炎發生之操作型定義 | **腎切片病理診斷** |
| 主要指標 | C 指數、提前期、免除比例 | 多類別正確率、各類敏感度特異度、混淆矩陣 |
| 報告準則 | TRIPOD（預後） | **STARD／TRIPOD 診斷版** |
| 需要的理論 | 雙穩態＋臨界減速 | **只需潛在變數量測模型**；臨界減速降為次要軸 |

### 二、必須先認清的一件事

新題**不再需要分岔理論**。舊題的核心賣點是「回彈力正在流失」這個動態訊號，那是為了預測未來事件；新題問的是「現在這個訊號是誰發出的」，屬於結構問題而非動態問題。

保留下來的是量測模型 y_k = l_k·x + ε_k 與[交叉動差](../05_%E6%A6%82%E5%BF%B5%E7%AD%86%E8%A8%98/%E4%BA%A4%E5%8F%89%E5%8B%95%E5%B7%AE.md)的[誤差免疫](../05_%E6%A6%82%E5%BF%B5%E7%AD%86%E8%A8%98/%E8%AA%A4%E5%B7%AE%E5%85%8D%E7%96%AB.md)性質——這一部分反而在新題裡變成更直接的主角。捨棄的是雙穩態、μc、臨界減速的預警框架。

**這件事有得有失，必須誠實面對**：失去的是理論novelty（臨界減速應用於慢性病是白地）；得到的是一個統計上容易得多的問題（見肆章數值驗證：同一組資料量下，分類任務的 AUC 明顯高於預警任務）。

## 肆、公式改良（含數值驗證）

### 一、保留什麼、丟掉什麼

| 原公式 | 命運 | 理由 |
|---|---|---|
| 雙穩態方程、μc、臨界減速 | **丟掉**（或降為次要「病程速度」軸） | 新題不預測未來事件，不需要分岔 |
| y_k = l_k·x + ε_k 量測模型 | **保留並升格為主角** | 病因差異正是體現在負載向量 l 上 |
| 公式一 C_ab(0) = l_a·l_b·Var(x) | **保留但改用途** | 由「量潛在變異大小」改為「解出負載向量」 |
| 公式二 λ | **降為次要特徵** | 疾病節奏（血管炎快、糖尿病腎病變慢）仍有鑑別力，但不再是主軸 |
| 公式三 DNB 面板指數 | 保留為輔助 | — |
| 公式四 機制判別對 | **保留**，改判「訊號是真是雜訊」 | 仍是品質關卡 |

### 二、新的核心公式：負載比例指紋

**想法**：不同病因拉動同一組檢驗的「方式」不同。狼瘡腎炎會同時壓低補體、拉高抗雙股 DNA 抗體與蛋白尿；IgA 腎病變的補體多半不動而血尿明顯；膜性腎病變是大量蛋白尿而血尿與補體皆不顯著；糖尿病腎病變則所有免疫通道皆不參與。這些差異就是負載向量 l 的方向差異。

問題是負載的絕對大小估不出來（會與 Var(x) 糾纏），而且用對角線（各通道自身變異數）會被化驗誤差 σ_k 污染。**解法是用第三條通道當支點**：

　　**公式一′（負載比例，誤差免疫）**
　　l_a / l_b ＝ C_ac / C_bc　（c 為任一第三通道，c ≠ a, b）

推導只需一行：C_ac ＝ l_a·l_c·Var(x)、C_bc ＝ l_b·l_c·Var(x)，相除後 l_c 與 Var(x) 全部約掉，剩 l_a/l_b。**兩式的誤差項在期望值中皆為零**，故此比例不受任何通道的化驗誤差影響。需要 K ≥ 3 條通道；K ＝ 6 時每個比例有 4 個獨立估計可取中位數。

把所有比例對某一參考通道歸一化，得到**指紋向量**

　　**公式二′（指紋向量）**　f ＝ ( l_2/l_1, l_3/l_1, …, l_K/l_1 )

這個向量與病人的疾病嚴重度無關（Var(x) 已約掉）、與化驗誤差無關（ε 已消去），只反映「哪一種病在拉動這組檢驗」。

### 三、數值驗證結果

以四通道、真實負載 l ＝ (1.0, 0.6, −0.8, −0.5)、**刻意設定差異極大的化驗誤差** σ ＝ (0.5, 1.5, 0.3, 2.0) 生成資料檢驗：

| 檢驗項目 | 結果 |
|---|---|
| 公式一′ 估計負載比例（充足樣本） | l₀/l₁ 真值 +1.667，估 +1.819；l₀/l₂ 真值 −1.250，估 −1.268；l₁/l₃ 真值 −1.200，估 −1.225 |
| 對照：用對角線（變異數比）估同一量 | 真值 1.667，估 **0.748**；真值 1.200，估 **0.804** —— 被 σ 嚴重污染 |
| 秩檢定（單一潛在過程） | 相對殘差 0.022 |
| 秩檢定（**兩個潛在過程並存**，模擬混合病因） | 相對殘差 **0.297**，明顯偏離秩一 |

**第一個結論**：誤差免疫性質成立且效果顯著——用對角線會錯 50% 以上，用交叉動差誤差在 10% 以內。

**第二個結論（意外收穫）**：交叉共變異數矩陣若由單一潛在過程驅動，必為秩一；殘差顯著偏離秩一即代表**有第二個潛在過程在動**。這正好是「排除其他疾病」所需的工具：

　　**公式三′（混合病因偵測）**　秩一擬合之相對殘差 R；R 超過門檻 ⇒ 不只一個病理過程

臨床對應：狼瘡病人同時有糖尿病腎病變、狼瘡合併血栓性微血管病變、感染疊加。這類「不是單一病因」的情況，現行單點檢驗完全看不出來。

### 四、有限樣本的誠實檢驗（這一段最重要）

以真實可得的同日成套次數重跑：

| 同日成套次數 | 負載比例中位估計（真值 1.667） | 四分位距 | 符號正確率 |
|---|---|---|---|
| 8 | 0.52 | [−0.11, 1.17] | 72% |
| 12 | 0.78 | [0.25, 1.62] | 79% |
| 20 | 0.93 | [0.44, 1.65] | 84% |
| 34 | 1.15 | [0.68, 1.91] | 88% |
| 60 | 1.31 | [0.77, 1.87] | 88% |
| 120 | 1.44 | [1.03, 2.06] | 91% |

**逐人精確估計依然失敗**——這是你早已測繪過的第三面牆（分母帶雜訊的比值估計有系統性向零偏誤），新公式沒有推翻它，不要宣稱推翻。

但接著是關鍵發現：

| 同日成套次數 | 兩種病因之分類 AUC（單軸） |
|---|---|
| 12 | 0.791 |
| 20 | 0.812 |
| 34 | **0.869** |
| 60 | 0.921 |

**分類不需要無偏估計，只需要偏誤在兩組間相似而排序被保留。** 這就是新題在統計上比舊題容易的原因，也是為什麼同樣的資料量下，分類任務可以越過 0.8，而預警任務卡在 0.70。

必須標註的但書：上表為性質檢核，兩種病的負載差異由我設定（補體通道 −0.8 對 −0.05），真實疾病間的差異可能小得多；且未納入驗證偏誤與頻譜偏誤。**這些數字不得對外引用**，只用來說明「方向可行」。

### 五、次要特徵（併入分類器）

| 特徵 | 公式 | 鑑別意義 |
|---|---|---|
| 指紋向量 f | 公式二′ | 主特徵：哪一種病在拉動面板 |
| 混合殘差 R | 公式三′ | 是否不只一個病因 |
| 疾病節奏 λ | 原公式二 | 血管炎快、糖尿病腎病變慢、IgA 陣發 |
| 領先落後不對稱 | A_ab(Δ) ＝ [C_ab(Δ) − C_ab(−Δ)] / [C_ab(Δ) ＋ C_ab(−Δ)] | 哪條通道先動：狼瘡多為補體先降後蛋白尿升；IgA 為血尿與蛋白尿同步 |
| 機制判別對 | 原公式四 | 品質關卡：排除化驗端問題 |

領先落後不對稱是本次新增的第三個維度，尚未做數值驗證，列為待檢項。

## 伍、內容更正清單

以下逐項列出 v6 需要改寫之處。

### 一、必須整章重寫者

| 章節 | 原內容 | 改為 | 理由 |
|---|---|---|---|
| 壹、研究目的 | 分出誰需要提早切片（預後分流） | **在已知腎炎者中，判定最可能的病因；狼瘡為待排除候選之一** | 題目本身改變 |
| 貳、公式推導 | 兩個山谷、臨界減速、公式一至四 | 保留量測模型與誤差免疫推導；**刪去雙穩態與臨界減速**；新增公式一′、二′、三′ | 新題不需分岔理論 |
| 參、模擬驗證 | 七機制、地標式、神諭上限 | 改為**多病因生成器**：每種病因給定不同負載向量與節奏，檢驗指紋向量之可分性；判準改為多類別正確率 | 對象由「機制」變「病因」 |
| 肆、納入排除 | 確診時腎臟乾淨、排除既有腎病 | **完全反轉**：納入條件改為「已接受腎切片且有病理診斷者」 | 參考標準是切片 |
| 伍、CGRD 六步 | 可得性→變數→模型階梯→滾動地標→分流→自我檢驗 | 滾動地標與提前期**整段刪除**；改為橫斷式診斷準確度分析 | 不再有「提前多久」的問題 |

### 二、納入排除的具體改寫

| 項目 | 原（v6） | 新（v7） |
|---|---|---|
| 納入一 | 新確診 SLE | **接受腎切片且病理診斷可判讀者**（不限是否有 SLE） |
| 納入二 | 確診時腎臟乾淨 | **切片前具腎絲球疾病表現**（蛋白尿、血尿或腎功能異常） |
| 納入三 | 追蹤 ≥ 12 個月 | **切片前具足夠檢驗序列**（見納入四）；追蹤僅供次要分析 |
| 納入四 | 前後窗各 ≥ 2 次同日成套 | **切片日前 12 個月內 ≥ 8 次[同日多通道](../05_%E6%A6%82%E5%BF%B5%E7%AD%86%E8%A8%98/%E5%90%8C%E6%97%A5%E5%A4%9A%E9%80%9A%E9%81%93.md)成套**（依肆章表，8 次為下限、20 次以上較可用） |
| 排除一 | 基線已有腎炎 | **刪除**（現在正是要納入的人） |
| 排除二 | 90 日內發病 | **刪除**（不再有 incident/prevalent 之分） |
| 排除三 | 其他慢性腎病 | **反轉為分類標籤之一**（糖尿病腎病變是要被鑑別出來的類別，不是要被排除的人） |
| 排除四 | 追蹤不足 | 改為「切片前檢驗序列不足」 |
| 排除五 | 藥物型／皮膚型狼瘡 | 保留但意義改變：僅排除病理無法判讀者 |
| 排除六 | HIV | **保留**（法規要求，衛署醫字第 1010265098 號但書） |
| 排除七 | 未滿 18 歲 | **保留**（資料庫端執行） |
| 新增排除 | — | 切片檢體不足（腎絲球數不足、無免疫螢光）、移植腎切片、切片前 3 個月內曾接受可改變檢驗值之免疫抑制治療者（列為敏感度分析而非硬排除） |

### 三、參考標準與偏誤結構的改寫（新增章節）

| 項目 | 內容 |
|---|---|
| 參考標準 | 腎切片病理診斷（含免疫螢光與電顯結論）；狼瘡腎炎依 ISN/RPS 分類 |
| 分類標籤 | 建議先以五類起步：狼瘡腎炎、IgA 腎病變、膜性腎病變、糖尿病腎病變、其他／混合。類別數依 CGRD 實際件數決定 |
| **驗證偏誤（本設計最大弱點）** | 只有接受切片者才有標籤，故模型只適用於「已被醫師認為值得切片」的族群，不可外推至所有腎炎病人。此點必須寫進限制與標題 |
| 頻譜偏誤 | 單一醫學中心之切片族群偏向疑難或重症；病例對照式設計會高估效能（Wong 2024 之 AUC 0.99 即為警示） |
| 盲性 | 病理診斷之判讀不得知悉模型輸出；資料抽取時病理欄位與檢驗欄位須分開處理 |
| 報告準則 | 由 TRIPOD（預後）改為 **STARD 2015 ＋ TRIPOD 診斷版**；主要指標為混淆矩陣與各類敏感度特異度，不用 C 指數 |
| 對照模型 | 必須有一個「單點檢驗值多變量迴歸」對照組——因為 Chedid 2020 已證明它會失效，這正是你要超越的基準 |

### 四、CGRD 申請內容的異動

你說主要仍依原先定義，這在**檢驗欄位**上大致成立，但有三處必須改：

| 欄位群 | 原申請 | 異動 | 必要性 |
|---|---|---|---|
| 檢驗通道 C1–C6 | UPCR、肌酸酐、C3、C4、抗雙股 DNA、尿沉渣紅血球 | **保留全部** | 這仍是核心面板 |
| 採檢時間戳、方法／試劑碼、儀器碼 | 已申請 | **保留，重要性不變** | 誤差獨立性分級仍是方法前提 |
| 病理報告 | ISN/RPS 分類（v4 已由選用升為必要） | **升為絕對必要，且需擴充**：非狼瘡診斷之完整病理結論、免疫螢光型態、電顯結論 | 這是新題的參考標準，沒有它整個研究不成立 |
| 疾病特異血清學 | 未申請 | **新增**：抗 PLA2R、ANCA（MPO／PR3）、抗腎絲球基底膜抗體、免疫球蛋白 A、蛋白電泳與游離輕鏈、B 型與 C 型肝炎、糖化血色素 | 這些是鑑別的關鍵通道；缺了它們，模型會被批評連標準流程都不如 |
| 世代定義 | 新診斷 SLE（重大傷病登錄） | **改為切片登錄／病理報告為索引** | 世代反轉 |

**須預先想好的一個反駁**：若加入抗 PLA2R 與 ANCA，許多鑑別直接被單一檢驗解決，你的方法還剩多少價值？答案要寫進計畫書：**本方法的目標族群是標準血清學陰性或不典型者**（Sciascia 2025 那 5 位即為此類），而非取代已有明確標記的病。這個定位要在標題與研究目的就講清楚，不要等審查者問。

### 五、假說改寫建議

| 編號 | 新假說 | 可被否證之預測 |
|---|---|---|
| H1 | 跨通道指紋向量對病因之區辨力，優於同一組檢驗之單點數值多變量模型 | 多類別正確率差異之信賴區間下界大於零；單點模型預期表現接近 Chedid 2020 之失效結果 |
| H2 | 指紋向量之效能依賴誤差獨立性 | A 級配對優於 C 級配對，差異顯著 |
| H3 | [秩一殘差](../05_%E6%A6%82%E5%BF%B5%E7%AD%86%E8%A8%98/%E7%A7%A9%E4%B8%80%E6%AE%98%E5%B7%AE.md) R 可偵測混合病因 | 病理報告載有兩種以上病變者，其 R 顯著高於單一診斷者 |
| H4 | 於標準血清學陰性子群中，本方法仍保有區辨力 | 該子群之多類別正確率顯著高於隨機 |
| H5（次要） | 疾病節奏 λ 與領先落後不對稱可提供指紋向量之外的增量 | 加入後正確率提升之信賴區間下界大於零 |

H4 是本研究的價值所在，建議列為主要假說而非次要。

## 陸、風險清單

| 風險 | 說明 | 因應 |
|---|---|---|
| 同日成套次數不足 | 切片前 12 個月內要有 8 次以上同日多通道，可能只有少數病人達標 | 第一階段彙總計數先查；不足則放寬窗至 24 個月，或降級為可行性研究 |
| 切片前用藥干擾 | 許多人切片前已開始類固醇，檢驗值被藥物拉動 | 列為分層變項與敏感度分析；記錄切片前用藥 |
| 類別極度不平衡 | 狼瘡腎炎可能占多數，罕見病因件數過少 | 事前設定最低件數門檻；不足之類別併入「其他」 |
| 標籤只存在於已切片者 | 驗證偏誤，無法外推 | 寫進標題與限制，定位為「切片轉介族群之鑑別輔助」 |
| 與單一血清學重疊 | 抗 PLA2R 一項即可解決膜性 | 定位於血清學陰性子群（H4） |
| 失去理論 novelty | 臨界減速被丟掉 | 改以「常規檢驗的交叉動差指紋」為方法學賣點；誤差免疫性質與秩一混合偵測仍是原創組合 |
