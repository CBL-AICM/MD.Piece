# 長庚醫學研究資料庫(CGRD)資料申請表　附頁

## 欄位層級補充說明（對應申請表第七項之(十八)「其他」）

| 項目 | 內容 |
|---|---|
| 計畫名稱 | 以[同日多通道](../05_%E6%A6%82%E5%BF%B5%E7%AD%86%E8%A8%98/%E5%90%8C%E6%97%A5%E5%A4%9A%E9%80%9A%E9%81%93.md)檢驗之[交叉動差](../05_%E6%A6%82%E5%BF%B5%E7%AD%86%E8%A8%98/%E4%BA%A4%E5%8F%89%E5%8B%95%E5%B7%AE.md)偵測全身性紅斑狼瘡病人腎臟受累早期訊號之可行性：一項使用長庚研究資料庫之回溯性世代研究 |
| 計畫主持人 | ＿＿＿ |
| IRB 案號／申請編號 | ＿＿＿ |
| 申請院區 | 台北、林口 |
| 回溯檔案期間 | 2001年1月至2025年12月 |
| 填表日期 | 2026年8月23日 |

**說明目的**：本研究之方法核心為「同一次採檢中同時完成之多項檢驗，其化驗誤差彼此獨立時，該誤差可於通道間之交叉共變異數中相互抵消」。此性質使本研究得以完全使用臨床常規檢驗、不新增任何抽血；但相對地，對檢驗檔之欄位有超出一般申請的特定需求。以下逐項說明所需欄位、用途與不可得時之替代方案。

---

## 一、檢驗結果歷史檔／專科檢驗結果檔之欄位需求

| 欄位 | 用途 | 必要性 | 不可得時之替代 |
|---|---|---|---|
| 檢驗項目代碼與名稱 | 通道對應 | 必要 | 無替代 |
| 對應之 LOINC 碼（若院內有維護） | 跨院區、跨年度項目對齊 | 高度建議 | 以院內項目代碼加人工對照表替代 |
| 採檢日期 | 同日判定 | 必要 | 無替代 |
| **採檢時間戳（時分）** | 判定是否為同一次採檢（同批），為本研究之嚴格定義所需 | **關鍵** | 退為「同一就診序號＋同一採檢日曆日」之標準定義，並於研究限制中敘明 |
| **就診序號或檢驗單號（accession no.）** | 判定同一次採檢 | **關鍵** | 無替代；若不可得，同批判定僅能以日曆日為準，方法之前提大幅弱化 |
| 檢驗結果值與結果單位 | 通道數值 | 必要 | 無替代 |
| 參考區間上下限 | 標準化基準與檢驗方法變更之偵測 | 必要 | 以院內歷年方法變更紀錄替代 |
| **檢測方法或試劑代碼** | 化驗誤差獨立性分級（A／B／C 級） | **關鍵** | 退為以「檢驗項目代碼＋院區」作為平台代理變項 |
| **儀器代碼或分析平台** | 化驗誤差獨立性分級 | 高度建議 | 同上 |
| 執行檢驗之實驗室或院區 | 化驗誤差獨立性分級 | 必要 | 無替代 |
| 檢體種類（血清／尿液／全血） | 化驗誤差獨立性分級 | 必要 | 可由檢驗項目推定，但精確度下降 |
| 結果狀態旗標（溶血、脂血、檢體不足、重驗、拒收） | 前分析階段變異之控制 | 高度建議 | 略去，於限制中敘明 |

**關鍵欄位之說明**：上表標示為「關鍵」之四欄，決定本研究能否成立。補體 C3 與 C4 於多數實驗室以同一免疫比濁儀同盤測定，其化驗誤差高度相關，依本研究之判準不得單獨用於估計；必須以「尿液檢體對血清檢體」「不同分析原理」之配對為主要分析。若無法區辨檢測方法與儀器，即無法判定哪些配對符合此條件，研究將退為描述性可行性評估。

## 二、須申請之檢驗項目清單

| 通道 | 檢驗項目 |
|---|---|
| C1 尿蛋白／肌酸酐比 | 隨機尿尿蛋白定量、尿肌酸酐、尿蛋白／肌酸酐比（UPCR）、24小時尿蛋白、尿液試紙蛋白半定量 |
| C2 腎功能 | 血清肌酸酐、系統推算之 eGFR（若有）、血中尿素氮 |
| C3、C4 補體 | 補體 C3、補體 C4、總補體活性 CH50（若有） |
| C5 自體抗體 | 抗雙股DNA抗體（含定量值與檢測方法）、抗核抗體、抗 Sm 抗體 |
| C6 尿沉渣 | 尿沉渣紅血球、尿沉渣白血球、尿沉渣圓柱（紅血球圓柱、白血球圓柱、細胞性圓柱） |
| 輔助 | 血清白蛋白、血色素、血小板、白血球、紅血球沉降速率、C反應蛋白 |
| 混淆排除 | 尿液白血球酯酶、亞硝酸鹽、尿液細菌培養結果（用於判定活動性尿沉渣時排除泌尿道感染） |

## 三、尿沉渣報告方式之特別需求

本研究之主要結局包含「活動性尿沉渣」，故尿沉渣之報告方式直接決定結局能否判定。

| 需求 | 說明 |
|---|---|
| 尿沉渣紅血球之報告形式 | 請提供原始報告形式（每高倍視野計數，或半定量分級碼如 0-2／3-5／5-10／>10／1+／2+ 等） |
| 分級與計數之對照表 | 若採半定量分級，請併同提供院內分級定義與其對應之每高倍視野計數區間 |
| 跨年度與跨院區之方式變更紀錄 | 顯微鏡人工鏡檢與流式尿沉渣分析儀之判讀基準不同，須據以分層 |
| 圓柱之報告欄位 | 請提供圓柱種類與有無之欄位，而非僅提供「異常／正常」之總結 |

## 四、解剖病理報告檔之需求範圍

| 需求 | 說明 |
|---|---|
| 申請範圍 | **僅需腎臟切片檢體之報告**，不需其他部位之病理報告 |
| 首要需求欄位 | ISN/RPS 狼瘡性腎炎分類（第 I 至 VI 型）之結構化欄位 |
| 次要需求欄位 | NIH 活性指數、慢性化指數（若院內有結構化登錄） |
| 自由文字 | **原則上不申請**。惟本研究之主要結局定義要求 ISN/RPS 分類，若該分類僅存在於報告自由文字而無結構化欄位，則請說明，本研究將改採替代結局定義（接受腎切片且其後符合臨床定義者），或另案申請 |
| 理由 | 病理報告自由文字之敏感度與重新辨識風險較高，且可能使審查程序由簡易改為一般，故盡量限縮 |

## 六、重大傷病登錄資料

本研究之全身性紅斑狼瘡確診日，主要定義為重大傷病證明之登錄日。請確認此欄位於 CGRD 中之可得性；若不可得，改採次要定義（首次診斷碼後12個月內另有門診診斷至少2次或住院診斷至少1次，以首次診斷日為確診日）。

## 七、請於資料庫端執行之個案排除

為使交付檔案不含敏感族群資料，以下排除請於資料庫端逕行執行，交付檔案不包含該等個案之任何欄位。

| 排除對象 | 判定依據 | 理由 |
|---|---|---|
| 具人類後天性免疫不全病毒（HIV）陽性紀錄者 | 診斷碼 B20、Z21、042、V08；HIV 相關檢驗陽性結果；抗反轉錄病毒藥品處方紀錄 | 依衛署醫字第1010265098號公告第四款但書，簡易程序審查之範圍不含 HIV 陽性患者之病歷。交付檔案亦不含 HIV 相關檢驗值，故本申請表第五項勾選「否」 |
| 未滿18歲者 | 基準日之年齡 | 本研究僅納入成年人，申請表第五項因而勾選「否」 |

| 與衛生福利部資料科學中心之串接 | 不需要 |

| 影像檔案與影像號對應清單 | 不需要 |
| 健檢資料 | 不需要（申請表第六項勾選「否」） |

| 病理報告自由文字（原則上） | 見第四節 |
| 死因文字 | 僅需死亡日期 |

## 九、資料使用之兩階段安排

| 階段 | 內容 |
|---|---|
| 第一階段 | 彙總計數可行性查詢：僅取得符合納入條件之人數、其中具備同日多通道檢驗者之人數、以及狼瘡性腎炎事件數，不取得任何個人層級資料 |
| 第二階段 | 俟第一階段確認人數足以支持分析後，再依本附頁之欄位清單申請個人層級去識別化資料 |

採兩階段之理由，在於避免以推測數字填寫樣本規模，並使個人層級資料之調閱範圍限縮於確有分析價值者。若貴中心之作業流程不接受兩階段申請，請惠予告知，本研究將改為一次申請並於計畫書中調整敘述。
