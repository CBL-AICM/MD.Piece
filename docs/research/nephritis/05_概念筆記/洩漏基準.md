# 洩漏基準（M0）

## 問題

「哪些檢驗被開立」本身就編碼了臨床醫師的事前判斷——抗 PLA2R 只有在懷疑膜性時才會開，ANCA 只有在懷疑血管炎時才會開。一個模型可以純粹靠「有沒有驗這項」拿到高正確率，而完全沒學到任何生理訊號。

## 對策

建立 **M0：僅用「哪些檢驗被開立」之指示變數**的分類器，取得洩漏上界。

| 模型 | 內容 | 建立順序 |
|---|---|---|
| **M0** | 僅檢驗開立指示變數 | **第一** |
| M1 | 窗內最後一次各通道數值（單點基準） | 第二 |
| M2 | 指紋向量＋節奏＋領先落後 | 第三 |
| M3 | M2 但排除疾病特異血清學 | 第四 |

## 判定

**M2 未顯著超越 M0，即不得宣稱有生理訊號**，照實報告並停止。

## 為什麼順序重要

先看到 M2 的漂亮數字再回頭建 M0，人會有強烈動機去解釋為何洩漏不算數。M0 必須先建並定版，時間戳可稽核。
