# 交叉動差

本專案的數學核心。方法源頭為動態網路標記（[Chen 2012 動態網路標記DNB](../04_%E6%96%87%E7%8D%BB%E5%8D%A1%E7%89%87/Chen%202012%20%E5%8B%95%E6%85%8B%E7%B6%B2%E8%B7%AF%E6%A8%99%E8%A8%98DNB.md)），本研究為其面板縮編版（4 至 9 通道，原文獻假設上千變數）。

## 量測模型

　　y_k(t) ＝ Σ_m l_km · x_m(t) ＋ ε_k(t)

每項檢驗都是潛在驅動的有雜訊倒影；l_km 為負載，ε_k 為該通道自身的化驗誤差。

## 核心性質：[誤差免疫](%E8%AA%A4%E5%B7%AE%E5%85%8D%E7%96%AB.md)

各通道誤差彼此獨立時，交叉共變異數中誤差項期望值為零：

　　C_ab(0) ＝ Cov(y_a, y_b) ＝ Σ_m l_am · l_bm · Var(x_m)

**只用非對角元素**（對角線含 σ，一律不使用）。實測：只用非對角比含對角高約 14 個百分點。

## 單驅動情形下的負載比例

以任一第三通道 c 作支點相除，l_c 與 Var(x) 全部約掉：

　　l_a / l_b ＝ C_ac / C_bc　（需 K ≥ 3）

實測估計誤差 < 10%；對照使用各通道自身變異數比則誤差 > 50%。

## 已知邊界

見 [三面統計障壁](%E4%B8%89%E9%9D%A2%E7%B5%B1%E8%A8%88%E9%9A%9C%E5%A3%81.md) 與 [旋轉不確定性](%E6%97%8B%E8%BD%89%E4%B8%8D%E7%A2%BA%E5%AE%9A%E6%80%A7.md)。逐人精確估計不可行，但分類可行——分類只需保留排序，不需無偏估計。
