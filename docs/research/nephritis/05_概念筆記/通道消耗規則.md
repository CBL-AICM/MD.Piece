# 通道消耗規則

**在第一層用於排除的通道，第二層不得再用。**

這既是防洩漏，也是 [排除式級聯](%E6%8E%92%E9%99%A4%E5%BC%8F%E7%B4%9A%E8%81%AF.md) 之所以能解掉循環性漏洞的原因。

| 通道 | 第一層用途 | 第二層可否再用 |
|---|---|---|
| 抗核抗體、抗雙股 DNA、抗 Sm、抗 C1q | 排除狼瘡 | **不可** |
| 抗 PLA2R | 排除／確立膜性 | **不可** |
| ANCA、抗腎絲球基底膜抗體 | 排除血管炎與抗 GBM 病 | **不可** |
| 免疫固定電泳、游離輕鏈 | 排除副蛋白相關 | **不可** |
| C3、C4 | **不用於排除** | **可**，但僅以兩者的相對關係使用 |
| 尿蛋白、肌酸酐、尿沉渣、NLR、糖化血色素、血壓、血清 IgA | 不用 | 可 |

## C3、C4 的部分重用

第一層排除狼瘡靠自體抗體而非補體，所以補體保留給第二層。但它們對狼瘡本身仍有 AUC 0.83 的鑑別力（[Zorn-Pauly 2022 疑似SLE之標記比較](../04_%E6%96%87%E7%8D%BB%E5%8D%A1%E7%89%87/Zorn-Pauly%202022%20%E7%96%91%E4%BC%BCSLE%E4%B9%8B%E6%A8%99%E8%A8%98%E6%AF%94%E8%BC%83.md)），屬部分重用，須以 **S11 敏感度分析**驗證：完全拿掉 C3、C4 重跑，確認效果不是殘留的狼瘡訊號。

## 程式實作

執行期檢查：第二層特徵矩陣若含任何 G1／G2 封存欄位，拋出例外。
